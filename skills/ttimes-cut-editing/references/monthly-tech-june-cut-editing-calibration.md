## 목적

단독 진행자가 다섯 개 뉴스 항목을 연속 설명하는 브리핑형 콘텐츠의 컷편집 사례다. 박남규의 macro story edit, 이주환의 interview/local cleanup과 달리, 이미 완성된 큐시트와 정보량을 거의 그대로 보존하면서 **한 번에 막힘없이 설명한 것처럼 발화 표면을 정리하는 micro-edit pass**를 보여준다.

완전한 gold는 아니다. 고유명사 테이크 선택 오류 가능성, 독립 `.` 문단, 이중 마침표, 문단 간 중복 잔존이 있어 반대검토 결과도 함께 사용한다.

## 다섯 소식의 보존 단위

각 뉴스는 다음 구조를 완결한다.

```text
사건
→ 수치·근거
→ 의미 해석
→ 국가·기업 행동 제안
```

1. AI 모델 사용 제한 → 소버린 AI와 인프라 전략
2. 데이터센터 투자 열풍 → 버블 논쟁과 병목
3. Google I/O → 온디바이스 에이전트와 기업 AX
4. Computex → AI PC 표준 변화와 기업 구매 전략
5. WWDC → Apple의 Gemini 의존과 독립 전망

숫자·사례·전망·기업 시사점은 거의 모두 보호됐다. 이 포맷에서 번호표(`두 번째입니다`)와 각 소식의 결론, 마지막 월간 테마 회수는 story spine이다.

## 실제 PD 선택에서 관찰된 규칙

### 1. 완성 재발화가 있으면 실패 테이크만 국소 제거

- `이 서비스에 미국인 이외에 다른 타국인 그러니까` → `외국인들은`
- `AI 데이터센터로 구동되는 약` → `AI 데이터센터로 운영되고 있는`
- `그게 이제 올해 드디어 꽃을` → 뒤의 완성 비유
- `물론 필요에 따라서 파운데이션,` → 뒤의 완성 문장
- `더 나아가서는 더 나아가서는` → 한 번만 유지

### 2. 내용은 줄이지 않고 예시·평가 수식만 포괄 명제로 압축

실질 콘텐츠 축약:

- 화학 공격 등 위험 예시 열거 → `국가 안보에 심각한 문제를 일으킬 해킹 악용 우려`
- `말로만 선언할 게 아니라… 최소한의 투자` → `데이터센터 AI 인프라 투자는 필요`

두 번째 컷은 정책 비판 강도를 약화시키므로 방향성에 따라 조건부다.

### 3. 숫자는 곧 논증이므로 보호

보존된 예:

- 미국 12~15GW, 한국 725MW, 미국 2030년 150GW
- 중국 2조 위안·약 450조 원, 자국 인프라 80%
- AI 투자 1조 달러, 2030년 5~7조 달러
- 데이터센터 지연 75건·약 200조 원
- RTX 장비 가격, 1조 파라미터, 200B 모델

### 4. 챕터 번호와 월간 회수 결론을 보호

`두 번째입니다`, `세 번째입니다`, `네 번째`, `다섯 번째`는 단순 연결어가 아니라 소식 구조의 내비게이션이다. 마지막의 Google I/O–Computex–WWDC를 온디바이스 AI로 묶는 결론도 보호한다.

## 중단 샌드위치

25:56~27:28에는 다음이 연쇄된다.

```text
본문 말미의 매달린 `그런 측면에서 보면`
→ 관리사무소 소방점검 방송
→ 촬영시간 확인
→ 외부 방송 후반
→ `기업용 AI PC 시장이 성…` 실패 재시작
→ 27:28 완성 재시작
```

외부음 하나만 자르는 것이 아니라 **끊기기 전 매달린 시작 + 외부음 + 현장 반응 + 실패 재시작**을 하나의 오염 블록으로 심사해야 한다. 최종적으로는 마지막 완성 테이크와 앞의 완결 문장을 연결한다.

## 고유명사 충돌 규칙

문제 컷:

```text
삭제 후보: DGX 스파크 ...
유지 후보: RTX 스파크 / RTX 스테이션
뒤 잔존: 디지스파크 / 디지스 스테이션 / 알티스파크
```

이것은 유창한 테이크 선택으로 해결할 수 없다. 경쟁 테이크가 회사·제품·인물·수치에서 다르면:

1. 자동 선택 중단
2. 원음 재청취
3. 공식 표기 확인
4. 전역 accepted transcript의 엔터티 표기 통일
5. 확정 전 `REVIEW`

반복 횟수가 많은 표기를 정답으로 간주하지 않는다.

## 컷플랜 자체의 실패

- 관리사무소 방송 삭제 뒤 `.` 단독 문단
- 중복문 삭제 뒤 `거든요..`
- 문단 내부 중복은 제거했지만 다음 문단의 같은 명제는 잔존
- `DGX/RTX/디지스/알티스` 명칭 충돌
- `엔트로픽/엔트로빅/엔스트로픽`, `S26/C26`, `WWDC/WDC` 등 전역 표기 혼선
- 일부 불완전 문장 결합

컷 의미가 타당해도 문장부호 소유권, 문단 간 중복, 전역 엔터티 일관성이 실패하면 최종 컷편집 DOCX는 미완성이다.

## 세 사례와 함께 범용화할 규칙

1. source format을 먼저 판정한다. 준비된 단독 브리핑은 macro 재구성보다 micro cleanup을 기본값으로 둔다.
2. 경쟁 테이크의 고유명사·수치가 다르면 유창함보다 정확성을 우선하고 자동 선택하지 않는다.
3. accepted state의 회사·제품·인물·행사·수치 표기를 전역 검사한다.
4. 본문 중간 외부음은 중단 샌드위치 전체를 심사한다.
5. 즉시중복은 같은 문단뿐 아니라 이전·다음 문단까지 검사한다.
6. 구두점은 인접 삭제의 일부인지 소유권을 검사한다.
7. 빈/split `w:del`과 삭제 내부 strike 서식을 의미 컷으로 이중 집계하지 않는다.

## 월간 뉴스 브리핑에만 둘 규칙

- 각 뉴스에서 `사건→수치/근거→기업 시사점`을 완결한다.
- 뉴스 번호표와 소식 간 챕터 전환을 보호한다.
- 미래 기술·제품·행사명이 밀집하므로 에피소드 단위 명칭·수치 팩트체크 표를 둔다.
- `그런 측면에서`, `정리를 하면`, `어차피`는 키워드 일괄 삭제하지 않고 문단 간 기능 중복을 본다.
- 최종 월간 테마 회수 문장을 보호한다.
