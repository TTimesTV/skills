# 다른 채널의 유튜브 설명란 사례

2026-11-26에 채널별 공개 영상 한 편씩 확인했다. 각 영상의 구성은 아래 순서대로 요약했다.

| 채널 | 설명란 구성 | 실제 영상 |
| --- | --- | --- |
| 지식인사이드 | 출연자와 주제 소개 → 구독·좋아요 안내 → 해시태그 → 출연자 책 → 챕터 → 촬영일 → 출연 신청·SNS | [황철성 교수 인터뷰](https://www.youtube.com/watch?v=N3_JYPfwIH0) |
| EO Korea | 출연자 발언 → 창업 배경과 인터뷰 주제 → 한국어 더빙 안내 → 글로벌 채널·뉴스레터. 이 회차에는 챕터가 없다. | [Radical AI 창업자 인터뷰](https://www.youtube.com/watch?v=QoPKzR3SN1Q) |
| 안될과학 | 사건 소개 → 영상에서 다루는 내용 → 시청자에게 던지는 질문 → 해시태그 → 편집 크레딧·채널 링크. 이 회차에는 챕터가 없다. | [AI 수술 실험 편](https://www.youtube.com/watch?v=mfnH2MuxwMo) |
| Dwarkesh Patel | 한 문장 소개 → 전문 링크 → 챕터 5개 | [앤트로픽과 미 국방부 편](https://www.youtube.com/watch?v=KBPOTklFTiU) |

설명란 사례 비교나 개편을 요청받으면 영상별로 소개글, 챕터, 회차별 자료, 고정 링크의 순서를 비교한다. 각 사례는 해당 회차의 관찰이다. 티타임즈 기본 설명란은 승인된 업로드 형식을 따른다.
