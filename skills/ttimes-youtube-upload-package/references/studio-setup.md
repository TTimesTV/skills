# 티타임즈 YouTube Studio 설정

업로드 패키지에 대상 영상과 적용값, 근거, 확인이 필요한 항목을 정리한다. 담당자는 티타임즈TV 소유자 또는 편집자 권한이 있는 계정으로 Studio에 접속해 직접 입력하고 저장한다. 대상 영상 ID를 원고 및 납품 세트와 대조하고, 기준 영상은 별도로 표시한다. 썸네일은 사용자가 제공한 파일을 기준으로 안내한다.

| 항목 | 적용 기준 |
|---|---|
| 제목·설명 | 제공받은 유튜브 제목과 공용 본문을 각각 입력한다. 승인된 설명란의 크레딧·연락처·랜딩·챕터와 줄바꿈을 살린다. 길이가 다른 편집본은 챕터 시간을 확인한다. 기사 및 포털용 제목은 각 대상의 원고 항목에 사용한다. |
| 재생목록 | 지정된 목록을 사용한다. 회차 시리즈가 확정됐으면 시리즈의 실제 Studio 목록을 확인한다. 예를 들어 박종천 2편의 목록은 `30년 개발자의 기업 분석`이다. 미발행 인계 중의 재생목록 처리는 [저장 전후 필수 확인](publishing-workflow.md#저장-전후-필수-확인)을 따른다. |
| 엔딩 화면 | 아래 `최종 화면 배치와 타이밍` 기준을 적용한다. 이전 공개본의 배치를 가져오고, 검색 결과가 없으면 `동영상 2개, 구독 1개` 템플릿을 사용한다. |
| 촬영일 | 월별 일정표, 촬영 기록 또는 사용자가 준 날짜로 `녹화 날짜`를 채운다. 근거가 없으면 미확인으로 남긴다. |
| 해시태그·태그 | 설명의 `#해시태그`와 Studio 고급 설정의 별도 `태그` 칸을 확인한다. 기준 회차의 확정 태그를 복제할 때는 승인된 개수와 문구를 보존한다. 새 회차의 초안은 본 스킬의 기본 개수를 따른다. |
| 카테고리·언어 등 | 카테고리, 원본 음성 언어, 제목·설명 언어를 확인한다. 박종천 2편의 예시는 과학기술·한국어다. 시청자층과 라이선스는 회차의 확인된 값과 승인된 채널 기준을 따른다. |
| 수익 창출 | 영상별 광고 켜짐·꺼짐, 중간 광고, 광고 적합성 상태를 확인한다. 승인된 광고 설정을 적용하며, 편집본 길이가 다르면 중간 광고의 위치를 해당 버전에서 검증한다. 광고 적합성 설문은 실제 영상에 근거해 판단한다. |
| 언어·더빙 | 최종 승인된 언어별 MP3, SRT, 번역 제목과 설명을 각 언어에 맞춰 등록한다. 영어와 일본어는 각각 해당 항목, 대만판은 `중국어(대만)`을 사용한다. 기준 영상의 표시 언어가 실제 자료와 다르면 실제 언어에 매핑하고 그 차이를 기록한다. 기존 트랙의 상태와 파일·대상 길이를 확인한다. |
| 공개 상태·예약 | 일부 공개를 확인하고 저장한 뒤, 세부정보를 다시 열어 일부 공개가 유지되는지 검증한다. 공개·예약은 별도 승인 범위다. 이미 공개된 영상의 보완 작업은 대상과 변경 범위가 명시된 경우에 한하며 공개 상태는 유지한다. |

확인된 값과 담당자가 확인할 값을 복사용 원고 밖에 표시한다. 저장 후 제목, 설명란(`00:00`부터 시작하는 챕터 포함), 섬네일, 재생목록, 태그, 녹화 날짜, 카테고리, 엔딩 화면, 수익 창출과 공개 상태를 다시 확인한다. 더빙은 처리 중, 게시됨, 실패를 구분한다.
## 고정 설정과 회차별 변경

사용자 2026-11-26 지시: 대부분의 Studio 설정은 승인된 채널·시리즈 기준을 재사용한다. 반복해서 설정값을 묻지 않고 제목·본문·챕터·태그·제작진·촬영일·엔딩 추천 영상 등 회차별 항목을 확인한다. 광고 적합성 판단과 중간 광고 위치는 실제 영상에 맞춰 검증한다.

사용자가 `랜딩 재생목록 1`, `오른쪽 영상`이라고 부르는 것은 이 문맥에서 엔딩 화면의 추천 영상 두 자리를 뜻한다. 실제 Studio의 시리즈 재생목록 필드와 구분한다. 랜딩 기사 URL 자체를 재생목록 ID로 취급하지 않으며, 기사에서 실제 YouTube URL을 확인한다. 오른쪽 추천은 위 기준으로 자율 선택하고 선택한 영상과 근거를 인계 시 짧게 남긴다.

## 최종 화면 배치와 타이밍

1. `동영상에서 가져오기`에서 티타임즈TV의 이전 공개본 중 같은 엔딩 배치를 쓰는 영상을 찾는다. 선택 창이 비어 있으면 제목이나 영상 ID로 검색한다. 가져올 수 없으면 `동영상 2개, 구독 1개` 템플릿을 선택하고, 각 카드의 `특정 동영상 선택`에서 URL로 지정한다. `내 동영상 검색`에 결과가 없으면 `다른 채널의 동영상 검색`에 전체 YouTube URL을 넣어 조회할 수 있다.
2. 왼쪽에는 사용자가 준 랜딩 기사에 실제로 삽입된 YouTube 영상, 가운데에는 티타임즈TV 구독 버튼, 오른쪽에는 연관 티타임즈 영상 한 편을 둔다. 오른쪽은 같은 출연자의 이전 촬영분 중 가장 최근의 관련 공개 영상을 우선한다. 예를 들어 박종천 2편은 같은 촬영분의 1편보다 이전 촬영분을 우선한다. 적합한 이전 촬영분이 없으면 주제가 직접 이어지는 공개 영상을 고른다. 현재 영상 및 왼쪽 영상과 중복하지 않는다.
3. 아웃트로에서 `구독하기` 화살표가 나타나는 프레임에 세 요소의 **시작점**을 맞춘다. 구독 버튼은 화살표 바로 아래에 두고, **종료점**은 세 요소 모두 대상 영상의 마지막 프레임에 고정한다. 아웃트로가 다른 회차는 대상 최종본에서 구독·추천 영역이 나오는 컷을 찾는다. 끝부분을 미리 재생해 두 영상 카드가 본편이나 마지막 자막을 가리지 않는지 확인한다. 저장 뒤 배치, 추천 대상, 시작·종료점을 다시 확인한다.

## 담당자가 Studio에서 직접 반영하기

1. 티타임즈TV 소유자 또는 편집자 권한이 있는 Google 계정으로 YouTube Studio에 로그인하고, 선택된 채널이 **티타임즈TV**인지 확인한다.
2. 최종본 링크가 있으면 해당 ID의 세부정보를 연다. 최종 파일만 받았으면 `만들기 → 동영상 업로드`에서 파일을 올린다. 영상 ID, 파일명, 길이를 대조한 뒤 복사용 문안과 위 설정값을 입력한다.
3. 일부 공개 상태를 확인한 뒤 저장한다. 세부정보를 다시 열어 실제 저장값과 공개 상태를 확인한다. 댓글은 기본 작업에서 제외한다. 댓글을 별도로 요청받은 경우 작성 명의가 티타임즈TV인지 먼저 확인하며, 명의가 확인되지 않으면 게시하지 않는다.
