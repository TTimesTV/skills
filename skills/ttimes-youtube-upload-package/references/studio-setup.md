# 티타임즈 YouTube Studio 설정

업로드 패키지를 만들 때 대상별 적용값, 근거, 확인이 필요한 값을 정리한다. 실제 반영 요청에는 승인된 티타임즈 편집자 세션과 사용자가 지정한 업로드 CLI를 사용한다. 대상 영상 ID를 원고 및 납품 세트와 대조한다. 기준 영상이 있으면 기준 영상 ID를 별도로 식별하고 해당 영상에서는 설정을 조회한다. 사용자가 제목 유지 등 예외를 지정하면 그대로 따른다. 썸네일 제작·등록은 별도로 요청받은 경우에만 한다.

| 항목 | 적용 기준 |
|---|---|
| 제목·설명 | 제공받은 유튜브 제목과 공용 본문을 각각 입력한다. 승인된 설명란의 크레딧·연락처·랜딩·챕터와 줄바꿈을 살린다. 길이가 다른 편집본은 챕터 시간을 확인한다. 기사 및 포털용 제목은 각 대상의 원고 항목에 사용한다. |
| 재생목록 | 지정된 목록을 사용한다. 회차 시리즈가 확정됐으면 시리즈의 실제 Studio 목록을 선택한다. 예를 들어 박종천 2편의 목록은 `30년 개발자의 기업 분석`이다. |
| 엔딩 화면 | Studio에서 `동영상에서 가져오기`로 기준 또는 최신 동영상의 배치를 불러온다. 이번 회차에 지정된 추천 영상으로 연결하고, 구독 버튼과 나머지 요소는 가져온 배치를 따른다. 박종천 2편의 추천 영상 예시는 박종천 1편이다. 대상 영상의 끝부분에서 배치·추천 대상·표시 시간을 확인한 뒤 저장한다. |
| 촬영일 | 월별 일정표, 촬영 기록 또는 사용자가 준 날짜로 `녹화 날짜`를 채운다. 근거가 없으면 미확인으로 남긴다. |
| 해시태그·태그 | 설명의 `#해시태그`와 Studio 고급 설정의 별도 `태그` 칸을 확인한다. 기준 회차의 확정 태그를 복제할 때는 승인된 개수와 문구를 보존한다. 새 회차의 초안은 본 스킬의 기본 개수를 따른다. |
| 카테고리·언어 등 | 카테고리, 원본 음성 언어, 제목·설명 언어를 확인한다. 박종천 2편의 예시는 과학기술·한국어다. 시청자층과 라이선스는 회차의 확인된 값과 승인된 채널 기준을 따른다. |
| 수익 창출 | 영상별 광고 켜짐·꺼짐, 중간 광고, 광고 적합성 상태를 확인한다. 승인된 광고 설정을 적용하며, 편집본 길이가 다르면 중간 광고의 위치를 해당 버전에서 검증한다. 광고 적합성 설문은 실제 영상에 근거해 판단한다. |
| 언어·더빙 | 최종 승인된 언어별 MP3, SRT, 번역 제목과 설명을 각 언어에 맞춰 등록한다. 영어와 일본어는 각각 해당 항목, 대만판은 `중국어(대만)`을 사용한다. 기준 영상의 표시 언어가 실제 자료와 다르면 실제 언어에 매핑하고 그 차이를 기록한다. 기존 트랙의 상태와 파일·대상 길이를 확인한다. |
| 공개 상태·예약 | 공개 전 영상의 작업 완료 상태는 `일부 공개`다. 이 상태에서 승인된 설정과 언어별 자료의 등록·검증을 마치고 사용자에게 인계한다. 공개 전환이나 공개 예약은 사용자가 명시적으로 요청한 경우에 실행한다. 이미 공개된 영상의 보완 작업은 현재 공개 상태를 유지한다. |

조회하거나 적용한 값을 복사용 원고 밖에 간단히 남긴다. 실제 반영 후에는 Studio에서 다시 열어 저장 여부를 확인한다. 더빙은 `처리 중`, `게시됨`, `실패`를 구분하며, 설정 화면 접근만 확인한 경우는 변경 검증과 구별한다. 본인 인증이 뜨면 전용 창을 유지해 사용자가 직접 인증할 수 있게 한다.
## 전용 Chrome에서 Studio 열기

1. 각 담당자는 본인 PC의 Studio 전용 Chrome 프로필에 **자기 Google 계정으로 직접 로그인**한다. 해당 계정에 티타임즈TV 채널 편집자 권한이 있어야 한다. 로그인 만료나 본인 인증이 뜨면 담당자가 해당 창에서 직접 완료한다. 로그인 정보와 브라우저 프로필은 각 담당자의 PC에서 관리한다.
2. 담당자가 지정한 Playwright CLI가 해당 프로필로 실행 중이면 그 세션을 재사용한다. 작업 전 계정 전환 메뉴에서 현재 담당자 계정을 확인하고, 티타임즈TV Studio에서 채널명과 `편집자` 표시를 확인한다. 개인 채널이 열리면 티타임즈TV로 전환한다. 계정이나 권한이 확인되지 않으면 작업을 보류한다. 프로필이 다른 창에서 사용 중이면 그 창의 작업을 보존한다.
3. CLI 안에서 대상 영상의 세부정보를 열고 영상 ID와 표시 제목을 확인한다. 편집기는 왼쪽 메뉴의 **편집기**를 선택한다. 주소가 대상 영상의 `/editor`인지, 화면에 **트림 & 자르기**가 보이는지 확인한다. 사용자가 화면 열기만 요청했다면 그 상태로 창과 CLI를 유지한다.
4. 세부정보·편집기 접근 확인과 실제 변경 저장 검증을 구분한다.
5. 실행 도구가 명령을 정책상 거절하면 거절된 명령과 실행 단계를 기록한다. 동일한 거절 동작을 다른 명령으로 포장해 재시도하지 않는다. 관찰된 오류에 따라 정책 거절, 프로필 사용 중, Studio 인증 또는 권한 문제를 구분한다.
