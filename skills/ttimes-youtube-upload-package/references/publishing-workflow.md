# 티타임즈 미발행 등록 절차

전체 등록 요청의 순서는 **YouTube Studio → 네이버 블로그 → 티타임즈 CMS**다. 플랫폼별 요청은 지정된 범위만 처리한다. 문안 준비 또는 절차 설명 요청은 복사용 자료와 체크리스트로 인계한다. 실제 등록을 요청받은 경우에만 승인된 계정과 채널에서 작업한다. 브라우저 작업은 사용자 작업 지침에 따라 Aside Browser MCP를 사용한다.

## 저장 전후 필수 확인

| 플랫폼 | 허용된 인계 상태 | 저장 전 직접 확인 |
|---|---|---|
| YouTube | **일부 공개** | 대상 영상 ID와 티타임즈TV 채널을 대조하고 `일부 공개`를 선택한다. 공개 재생목록은 일부 공개 영상도 목록 방문자에게 노출할 수 있으므로 미발행 작업에서 추가를 보류한다. 목록의 공개 범위를 확인할 수 없을 때도 추가하지 않고 확인 상태를 남긴다. |
| 네이버 블로그 | **미발행 임시저장** | 티타임즈 블로그의 대상 초안을 확인하고 편집 상단 `저장`을 사용한다. `발행` 및 예약 발행은 미발행 등록 단계에 포함하지 않는다. |
| CMS | **미표출 `0` / 임시저장** | `기사표출 설정`에서 `다음 콘텐츠 뷰 전송용 카테고리 → 설정안함`, `표출설정 → 미표출`을 각각 확인한 뒤 `임시저장`한다. |

`업로드`, `등록`, `올려줘`, `진행`은 위 상태까지의 작업이다. 공개, 예약, 포털 전송은 별도 명시적 요청이 필요하다. 기본 작업에서 댓글 작성·게시·고정을 제외한다. 이미 공개된 영상이나 글이 기준 자료로 열려 있으면 읽기용으로 사용하고, 기존 공개물 수정은 대상과 변경 범위가 명시된 경우에만 처리한다.

저장 후 같은 항목을 다시 열어 저장값과 공개 상태를 검증한다. 저장 전 상태나 대상이 확인되지 않으면 해당 단계에서 저장을 중단한다. 저장 후 확인 실패는 완료로 보고하지 않는다. 전체 등록에서는 앞 단계의 영상·초안과 공개 상태를 확인한 뒤 다음 플랫폼으로 넘어간다. 오류가 나거나 저장 결과가 불명확하면 기존 ID와 초안 목록을 먼저 확인한 후 재시도해 중복을 막는다. 조회와 복사용 원고 준비는 계속할 수 있다.

## 1. YouTube Studio

[Studio 설정](studio-setup.md)을 따른다. 최종 영상 링크가 있으면 그 ID의 세부정보를 열고, 최종 파일만 받은 경우 업로드하여 ID와 파일을 대조한다. 제목·설명란·섬네일·재생목록·태그·녹화 날짜·카테고리·엔딩 화면·수익 창출을 확인한다. 설명의 `00:00`과 앞광고·하이라이트·본편 챕터는 대상 최종본 기준으로 검증한다. `일부 공개`로 저장하고 세부정보를 다시 열어 반영 여부를 확인한다. 이후 네이버와 CMS에는 이렇게 확인한 최종 영상 URL을 사용한다.

## 2. 네이버 블로그

1. [티타임즈 블로그](https://blog.naver.com/ttimes_tv)의 `글쓰기`로 들어간다. 같은 회차 임시저장이 있으면 그 글을 연다. 제목에 세트의 `<네이버 다음 제목>`을 입력하고 **나눔바른고딕 32**를 적용한다. 카테고리는 해당 시리즈 기존 글을 참고한다.
2. 본문 맨 위를 한 줄 비우고 최종 유튜브 영상을 **재생 가능한 영상 블록 하나**로 삽입한다. 삽입에 사용한 URL 문자열을 지운다. 영상 아래는 빈 줄 한 줄을 둔다.
3. 본문 첫머리에 `[TTimes = 이름 직함, 이름 직함]` 형식으로 확인된 제작진을 표시하고 세트 본문을 이어 넣는다. **나눔고딕 16, 왼쪽 정렬**을 적용한다. 참고 회차의 제작진 표기는 `[TTimes = 배소진 기자, 박의정 영상디자이너]`다.
4. 본문 뒤에 편집기의 **두 번째 유형 구분선**을 넣는다. `티타임즈 추천기사 ▼`는 **왼쪽 정렬**, 바로 아래 **추천 기사 제목이 놓인 줄만 가운데 정렬**한다. 세트의 랜딩을 해당 제목에 연결하고 주소가 독립 텍스트로 남아 있으면 지운다.
5. `저장` 후 임시저장 목록에서 해당 글을 다시 연다. 제목·본문 서식, 위쪽과 영상 아래 공백, 영상 재생, 구분선, 추천 기사 정렬과 링크, 미발행 상태를 확인한다. [반스앤노블 공개 글](https://blog.naver.com/ttimes_tv/224493213180)은 카테고리와 구성 참고용이다.

## 3. 티타임즈 CMS

**접속 전제는 회사 VPN 연결이다.** CMS 페이지가 네트워크 오류로 열리지 않으면 등록을 멈추고 사용자에게 “티타임즈 CMS에 접속하려면 VPN이 필요해요. VPN을 켜고 연결되면 알려주세요.”라고 안내한다. 사용자가 연결을 확인하면 같은 CMS 탭이나 대상 초안을 다시 열어 접속과 대상을 확인한 뒤 이어서 진행한다. VPN 연결 후에도 실패하면 실제 오류를 알린다. CMS 로그인 화면이 열렸거나 계정 권한 오류가 표시되면 해당 로그인·권한 단계를 안내한다.

1. `콘텐츠작성 → 영상뉴스작성`에서 시작한다. 같은 회차의 초안이 있으면 `콘텐츠리스트`에서 그 초안을 연다. 세트의 `<기사 제목>`을 입력하고 `해시태그 등록 관리`에 유튜브 설명과 동일한 세 개를 등록한다.
2. 사용자가 따로 준 **CMS용 리스트 이미지**를 `리스트 이미지(SIZE 1185 X 997)`에 등록하고 미리보기를 확인한다. 유튜브 섬네일과 구분하고 이미지가 미제공이면 입력 상태를 명시한다.
3. `기사본문 텍스트` 맨 위에 최종 유튜브 영상을 재생 가능한 플레이어로 **가운데 정렬**해 넣는다. 빈 줄 한 줄 뒤에 세트의 원문을 **왼쪽 정렬**로 넣는다. 영상 삽입에 사용한 URL 문자열이 본문에 남아 있지 않은지 확인한다.
4. `작성자 추가 등록 및 삭제`에서 확인된 내부 제작진을 중복 없이 등록한다. 편집·촬영·자료·진행·섬네일의 역할과 직함은 제작진 크레딧에서 각각 보존한다. 복사용 데이터는 [CMS 초안 양식](user-approved-two-block-contract-20261014.md)의 필드 순서를 따르고, 세트의 기존 참고 랜딩을 포함한다.
5. `기사표출 설정`에서 **전송용 카테고리 `설정안함` → 표출설정 `미표출` → `임시저장`** 순서로 진행한다. 저장 후 `콘텐츠리스트`에서 같은 ID를 다시 열어 제목, 해시태그, 리스트 이미지, 영상과 본문 정렬, 작성자, `미표출` 상태를 확인한다.
