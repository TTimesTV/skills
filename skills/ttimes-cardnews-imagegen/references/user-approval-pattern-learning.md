# TTimes 카드뉴스 — 사용자 승인 패턴 학습 루프

## 목적

매회 사용자가 고른 제목·본문·이미지와 수정 델타를 구조화해 다음 회차 후보 생성·순위화에 반영한다. 목표는 사용자를 흉내 내는 것이 아니라, **같은 포맷에서 반복적으로 승인된 편집 판단을 먼저 제안하는 것**이다.

## 권위 순서

1. 현재 회차의 사용자 명시 지시
2. 현재 회차에서 사용자가 확정한 문구·이미지
3. 동일 포맷의 반복 승인 패턴
4. 범용 TTimes 편집 규칙
5. 모델의 새 제안

묵시적 무응답은 승인으로 기록하지 않는다. `확정`, `굿`, `ㄱㄱ`, 직접 수정문 전달처럼 승인 의도가 명확한 경우만 기록한다.

## 매회 학습 절차

### 1. 후보 전

- `editorial-preference-snapshot.json`을 읽는다.
- 동일 포맷의 `approved`·`revised` 신호를 우선 적용한다.
- 단일 회차에서만 나온 취향은 가설로 다루고, 세 편 이상 반복된 신호만 기본값으로 승격한다.
- 단, 사용자가 명시한 하드 규칙은 첫 회부터 즉시 고정한다.

### 2. 제목 후보

- 영상 전체 요약형 제목보다 타깃 독자가 자기 문제로 느끼는 긴장·오류·질문을 먼저 찾는다.
- 일반 대담형은 `구체적 대상 + 행동/판단 + 의외의 질문 또는 단정`을 우선한다.
- 후보마다 `hook`, `audience_tension`, `coverage`, `spoken_naturalness`를 내부 평가한다.
- 3~5개 후보만 제시하고, 선택 전에는 전체 카드를 렌더링하지 않는다.

### 3. 본문 후보

- `구체적 생활 장면·비유 → 해석 → 조직적 결론` 순서를 우선한다.
- 제목은 짧은 질문 또는 단정으로 만들고 한 줄 가능성을 먼저 확인한다.
- 본문은 일반 굵기, 핵심 결론 exact span만 강조한다.
- 사용자가 고친 조사·시제·복수형·쉼표·인용부호도 의미 있는 델타로 기록한다.

### 4. 이미지 후보

- 먼저 3~5개 **개념 후보**를 제시하고, 사용자가 고른 뒤 ImageGen을 실행한다. 다만 사용자가 바로 `ㄱㄱ` 하면 현재 최우선안을 생성한다.
- 직관성은 `본문을 읽기 전에도 핵심 동작이 보이는가`로 판단한다.
- 추상적 서버·관제실·가짜 UI보다 행동과 책임 주체가 보이는 물리적 비유를 우선한다.
- 거절된 이미지는 단순 미학 실패인지 메시지 전달 실패인지 구분해 기록한다.

### 5. 승인 후 기록

`record_editorial_approval.py append`로 다음을 남긴다.

- format / episode / artifact / field
- status: proposed / approved / rejected / revised
- candidate / final
- reason
- signals
- source: explicit_user / user_edit / observed_choice

같은 사건에서 제안문과 수정문이 다르면 `revised` 한 건으로 기록하고, `candidate`와 `final`을 모두 보존한다.

### 6. 스냅샷 갱신

회차 종료 때:

```bash
python scripts/record_editorial_approval.py summarize \
  --ledger references/editorial-approval-ledger.jsonl \
  --output references/editorial-preference-snapshot.json
```

다음 회차는 JSONL 전체를 매번 읽지 않고 스냅샷을 먼저 사용하되, 충돌 시 최근 사용자 지시와 원장 이벤트가 우선한다.

## 2026-08-31 일반 대담형에서 확인된 초기 패턴

- 표지는 전체 영상 요약보다 HR 독자가 즉시 반응할 성과평가 오류 질문을 선택했다.
- 본문은 생활 비유를 먼저 제시한 뒤 조직의 책임과 시스템 해법으로 끝낼 때 승인도가 높았다.
- 한 줄에 들어가는 문장을 임의로 쪼개는 것을 거부했다.
- `많이 써도`보다 완료된 사용량을 가리키는 `많이 썼어도`를 선택했다.
- 추상적 관제실·서버 시각화보다 자동 물류 분류기처럼 동작이 바로 보이는 비유를 선택했다.
- 최종 비주얼은 ImageGen으로 만들고, 정확한 한국어는 후합성하거나 생략한다.
- 카드뉴스 야마와 업로드 메타데이터는 서로 다른 권위 원장으로 유지한다.

## 과적합 방지

- 김지현 회차의 특정 명사·토큰 비유를 다른 주제에 그대로 복제하지 않는다.
- 동일 신호가 다른 회차에서 반복되는지 확인한 뒤 포맷 기본값으로 승격한다.
- 사용자의 최신 명시 수정은 과거 빈도보다 항상 우선한다.
- 승인된 최종 문장을 경쟁 채널·다른 출연자 문장에 복제하지 않는다.
