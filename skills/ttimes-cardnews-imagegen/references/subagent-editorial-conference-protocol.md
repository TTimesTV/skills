# TTimes 카드뉴스 Subagent 편집회의 프로토콜

## 적용 시점

TTimes 일반 대담형을 포함해 영상에서 제목과 스토리라인을 새로 뽑아야 하는 카드뉴스에 적용한다. 단순 오탈자 수정이나 이미 승인된 원고의 색상·좌표 수정에는 다시 회의를 열지 않는다.

## 불변 순서

```text
원문·자막·음성 확보
→ subagent 독립 검토
→ 편집회의 의장 합의안
→ 사용자 원고 승인
→ 표지·본문·마지막 장 디자인
```

원고 승인 전 전체 카드 이미지를 먼저 만들지 않는다.

## Subagent 역할

### 1. 제목·스토리 편집자

- 영상 전체를 요약하지 않는다.
- 가장 재미있고 독립적으로 완결되는 질문·주장 하나를 고른다.
- 표지 제목을 먼저 제안한다.
- 그 제목을 푸는 데 필요한 독립 비트만 배열한다.
- 장수를 먼저 정하지 않는다.
- 제목만 이어 읽어도 `질문 → 전개 → 답`이 성립하는지 검사한다.

### 2. 원문 검증·반론 편집자

- 각 주장과 인과를 실제 자막·음성·타임코드에 연결한다.
- 직접 인용과 편집 요약을 구분한다.
- 화자를 문단 위치로 추정하지 않는다.
- 원문에 없는 기술 설명·수치·필연적 인과를 삭제하거나 완화한다.
- 제목과 마지막 인용이 실제 원문으로 함께 성립하는지 검증한다.

### 3. 모바일 카드 카피 편집자

- 제목 1행 우선, 본문은 선택된 사용자 승인 포맷의 고정 크기에서 읽히는 분량으로 쓴다.
- 한 장 안에 인과적으로 결속된 메시지는 2~4개까지 담을 수 있다.
- 정보 밀도를 높이라는 요청을 장수 증가로 해석하지 않는다.
- 강조는 별도 하단 카피를 만들지 않고 본문 속 정확한 핵심 구절에 `[H]...[/H]`로 표시한다.
- 강조 위치는 중요도에 따라 앞·중간·마지막 모두 가능하다.

### 4. 편집회의 의장

- 세 초안을 모두 읽고 충돌을 조정한다.
- 원문 검증자의 차단 판정을 우선한다.
- 제목을 먼저 확정하고, 본문 모든 장이 그 제목에 기여하는지 검사한다.
- 반복 페이지·장수 확보용 분리를 제거한다.
- 마지막 장은 단순히 강한 발언이 아니라 표지 제목과 본문 결론을 회수하는 실제 게스트 인용으로 선택한다.
- 최종 장수는 독립 비트 수로 결정한다. 특정 숫자로 고정하지 않는다.

## 필수 산출물

프로젝트 작업 폴더 아래에 다음을 저장한다.

```text
editorial_conference/
├── story_editor.md
├── source_editor.md
├── copy_editor.md
└── final_script.md
```

`final_script.md`에는 반드시 다음이 들어가야 한다.

1. 확정 표지 제목
2. 선택한 단일 논점
3. 카드별 제목·본문·인라인 강조 위치
4. 마지막 실제 인용·화자·직함
5. 원문 근거 타임코드
6. 삭제한 논점과 기각한 표현
7. 이번 에피소드의 장수와 그 이유

## 승인 게이트

다음을 모두 만족하기 전 렌더링하지 않는다.

- 표지 제목이 사용자 문구와 정확히 일치한다.
- 본문 제목만 읽어도 하나의 흐름이다.
- 각 장은 표지 질문을 이해하거나 답하는 데 필요하다.
- 삭제해도 흐름이 유지되는 장은 제거했다.
- 한 장에 합쳐도 고정 폰트로 읽히는 짧은 인과를 장수 확보용으로 나누지 않았다.
- 마지막 인용이 표지와 스토리를 회수한다.
- 직접 인용의 화자·구간·문구를 음성으로 검증했다.
- 사용자가 원고를 승인했다.

## 전역·포맷별 고정 타이포

- 표지 제목: Noto Sans KR Black 80px
- 마지막 인용: Noto Sans KR Black 50px
- 프로필: Noto Sans KR Black 30px

본문은 `approved-format-registry.json`을 따른다. 이중학–윤명훈과 원맨은 제목 74px, 본문·강조 35px이며, 박영선은 등록된 승인 렌더러의 계층을 유지한다. 일반 대담 등 미승인/별도 포맷은 해당 템플릿 규칙을 적용한다.

선택된 포맷의 고정 타이포가 안 들어가면 글자를 줄이지 않는다. 의미 단위 줄바꿈, 본문 재편집, 인과적으로 결속된 메시지의 압축 또는 독립 비트 분리를 다시 검토한다.
