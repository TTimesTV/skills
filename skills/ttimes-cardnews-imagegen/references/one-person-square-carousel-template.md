# TTimes 원맨 해설형 정사각 카드뉴스 템플릿

## 적용 범위

실제 제작 형식이 F1 원맨 전문가·기자 해설형으로 확인된 1080×1080 카드뉴스에 적용한다. 한 명이 보인다는 이유만으로 적용하지 않으며, F2 게스트 단독 대담·F4 데모·F5 브리핑과 구분한다.

## 편집 계약

```text
원문·자막·음성
→ story/source/copy subagent
→ chair synthesis
→ 표지 질문·명제 확정
→ 제목에 답하는 본문 N장
→ 제목을 회수하는 실제 원맨 발화
```

- 장수는 고정하지 않는다.
- 전체 영상 챕터를 요약하지 않는다.
- 한 장에 결속 가능한 2~4개 메시지를 장수 확보용으로 나누지 않는다.
- 마지막 장은 단순히 센 문장이 아니라 표지 제목의 답이어야 한다.

## 전역 고정 타이포·로고

- 표지 제목 80px
- 본문 제목 74px
- 본문/강조 35px, weight 560/720
- 마지막 인용 50px
- 프로필 30px
- 표지 로고 우측 상단
- 본문 로고 없음
- 마지막 로고 하단 중앙

## 표지

- exact article `_list_`를 정사각 크롭한다.
- 원맨이라고 전문가 얼굴을 발명하지 않는다. 실제 `_list_`가 로봇·제품·기업·현장 중심이면 그대로 보존한다.
- 실제 유튜브 썸네일에서 제목 위치·행 수·정렬·색상·질감만 가져온다.
- 정사각 표지의 공통 골격은 이중학·박영선 승인 표지 2종을 따른다: 절제된 암색 하단 그라데이션 + 하단 대형 제목 + 글자색 강조.
- 유튜브 썸네일의 빨간 직물판·불투명 색상판을 정사각 표지에 복사하지 않는다.
- 명명 시리즈가 검증되지 않으면 시리즈 배지를 발명하지 않는다.

## 본문

- 기본 분할은 비주얼 540px : 텍스트 540px의 정확한 1:1이다. 사용자가 별도 승인하지 않으면 사진을 얇은 상단 띠로 줄이지 않는다.
- 본문 골격은 이중학·박영선 승인 카드와 공통이다: 사진/글 경계에 걸친 `1·2·3` 순번판 → 독립 제목 구간 → 본문 구간. 시리즈별로 바꾸는 것은 색·격자 농도·순번판 조형·비주얼뿐이다.
- 제목과 본문을 한 덩어리 문단처럼 붙이지 않는다. 제목은 별도 시각 계층을 갖고, 본문은 충분한 좌우 여백 안에서 자연스럽게 좌측 정렬한다.
- 영상 화면·방송 프레임을 캡처해 본문 사진처럼 붙이지 않는다.
- 본문 장별 메시지를 설명하는 별도 1:1 개념 비주얼을 제작한다. 생성 원본과 최종 카드는 모두 1:1이어야 한다.
- 실제 회사·제품·수치·UI가 주장의 증거일 때만 공식 이미지·원자료를 사용한다. 이 경우에도 영상 캡처가 아니라 출처가 확인된 원본 자산을 확보한다.
- 원맨이라는 이유로 말하는 사람 캡처를 반복하거나 전문가 얼굴을 생성하지 않는다.
- 생성 비주얼에는 한글·영문·숫자·로고를 넣지 않고 확정 한국어는 후합성한다.
- 생성 비주얼은 한 장면·한 동작의 자연스러운 편집 일러스트를 우선한다. 겹친 잔상, 콜라주 레이어, 떠 있는 물체, 중복 손·팔, 과도한 망점·절취 효과, 가짜 포토리얼 CG를 금지한다. 로봇 손의 수·관절·천 접촉·중력에 따른 주름을 검수한다.
- 강조는 본문 속 정확한 구절에 인라인으로 적용한다. 마지막 문장 고정 금지.
- 이중학–윤명훈 승인 본문의 정보 밀도를 따른다: 본문 제목 74px, 본문·인라인 강조 35px, 장당 본문 공백 포함 약 95~115자. 표지 80px, 마지막 인용 50px, 프로필 30px은 유지한다.
- 이중학 승인본의 행 수를 흉내 내려고 원고에 강제 개행을 넣지 않는다. 원고는 완전한 문장·문단으로 저장하고, 렌더러가 35px·안전폭에서 의미를 훼손하지 않는 자동 줄바꿈을 수행한다. 종속절·조사·어미를 임의로 다음 행에 고립시키지 않는다.
- 자동 줄바꿈은 단순 폭 계산만 사용하지 않는다. `구겨지고 겹쳐진다`, `안전하게 반복할 수 있다`처럼 분리하면 문법 결속이 깨지는 어절 묶음은 내부 `[K]...[/K]` 분리금지 span으로 표시한다. `[K]`는 화면에 출력하지 않으며 행 위치를 지정하는 강제 개행이 아니다.
- 74/35에서 안 들어가면 폰트를 더 줄이지 않고 의미 단위 줄바꿈·문장 압축·페이지 기능을 재심한다.

## 마지막 장

- `_list_` 재사용 금지.
- 별도 배경에 실제 원맨 발화 50px, 검증된 사람/기관 프로필 30px, 하단 중앙 로고.
- 인용은 음성·타임코드로 검증한다.
- 개인 화자 신원이 없으면 임의 프로필을 만들지 않고 기관형 마무리를 사용자 승인받는다.
