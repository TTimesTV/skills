# 이중학의 사람과 기술 — 정사각 카드뉴스 고정 템플릿

## 적용 범위

`이중학의 사람과 기술` 영상·기사에서 진행자 이중학과 게스트의 대담을 1080×1080 SNS 카드뉴스로 만들 때 적용한다.

고정되는 것은 본문 장수가 아니라 **표지·본문·마지막 장의 디자인 및 편집 문법**이다.

## 전체 구조

```text
표지 1장
→ 본문 N장
→ 게스트 인용 마지막 장 1장
```

- 본문 장수는 대담의 독립적인 핵심 논점 수에 따라 결정한다.
- 장수를 맞추려고 같은 내용을 나누거나, 서로 다른 논점을 한 장에 합치지 않는다.
- 각 본문 장은 핵심 주장 하나만 담당한다.
- 권장 흐름: 쟁점 → 경험·근거 → 메커니즘 → 사람·조직의 함의. 소스에 없는 단계는 만들지 않는다.

## 1. 표지

- 해당 기사의 실제 TTimes `_list_` 이미지를 그대로 사용한다. ImageGen 재해석 금지.
- 중앙 1:1 크롭 후 1080×1080.
- 우측 상단 공식 TTimes 로고.
- 제목은 현재 기사/썸네일 문구 우선.
- 문구가 지나치게 길거나 이상할 때만 핵심을 보존해 편집한다.
- 제목 행 수를 1행·2행·3행으로 미리 고정하지 않는다. 문법 결속과 이미지 여백에 따라 자연스럽게 나눈다.
- 표지 제목: Noto Sans KR/CJK KR Black 80px 고정. 필요시 88~100% 장평 조절.
- 제목 색·위치·행 수는 기사별 사진과 문구에 따라 바꾸되 크기는 80px로 고정한다.

## 2. 본문 N장

### 고정 레이아웃

- 1080×1080.
- 상단 약 520px: 내용에 맞는 자연스러운 에디토리얼 사진 또는 필요한 실제 증거 이미지.
- 하단 약 560px: 제목+본문 정보판.
- 사진과 정보판 경계에 순번 `1, 2, 3…`.
- 순번판은 약 92×92px의 **각진 정사각형**. 원형·라운드 사각형 금지.
- 시리즈 배지 및 `이중학의 사람과 기술` 문구를 본문에 넣지 않는다.
- 본문 카드에 TTimes 로고를 넣지 않는다.

### 색과 타이포

- 정보판 배경: 딥 네이비 `#07112D`.
- 은은한 격자: `#182344`.
- 제목: 표지와 연결되는 연보라 `#8799FF`.
- 제목 폰트: Noto Sans KR Black 약 74px. 행 수는 고정하지 않고 자연스럽게 조판.
- 본문: Noto Sans KR Variable 35px / weight 560. 강조는 35px / weight 720.
- 본문 기본 글씨: 오프화이트/밝은 회색.

### 본문 형광펜

- 별도의 좌측 하단 강조 카피·독립 강조 박스를 만들지 않는다.
- 핵심 문장을 **본문 흐름 안에서 그대로** 강조한다.
- 형광펜 색: `#8799FF`.
- 형광펜 위 글씨: 흰색이 아니라 딥 네이비 `#07112D`.
- 글자의 실제 렌더링 바운딩박스를 기준으로 전체 획 높이를 감싼다.
- 검증 샘플 시작값: 위 7px, 아래 8px, 좌 7px, 우 10px.
- 글자가 가려지거나 형광펜이 낮게 깔리지 않도록 한다.
- 여러 줄을 강조하면 각 행의 높이와 행 사이 간격을 자연스럽게 유지한다.
- 강조 위치는 내용상 가장 중요한 문장으로 정하며, 고정적으로 마지막 문장일 필요는 없다.

### 사진

- 자연스러운 다큐멘터리·에디토리얼 사진 우선.
- 과도한 CG, 네온, 떠다니는 UI, 추상 화살표, 합성 티가 강한 개념도 금지.
- 실제 UI·차트·자료 사진이 증거라면 생성 이미지보다 원본 증거를 우선한다.
- ImageGen을 쓸 때는 텍스트·숫자·로고·워터마크를 생성시키지 않는다.
- 최종 상단 1080×520 크롭에서 핵심 인물과 행동이 남아야 한다.
- 사진의 손·얼굴·동물·도구·고삐 등 해부학과 연결 관계를 검수한다.

### 화자·문구

- 카드의 주인공은 원칙적으로 게스트.
- 진행자 이중학의 질문·발언은 편집 구조에 활용할 수 있으나 게스트 발언으로 귀속하지 않는다.
- 화자 라벨 없는 문단 위치만으로 인용 화자를 추정하지 않는다.
- `윤명훈 총괄의…`, `진행자 이중학 교수는…` 같은 불필요한 귀속형 머리말은 제거한다.
- 직접 인용은 실제 음성으로 화자·구간·문구를 확인했을 때만 따옴표 사용.
- 압축·의역·재배열 문장은 따옴표 없는 편집 요약으로 처리한다.

## 3. 마지막 장

- 사진 없이 딥 네이비·연보라 계열의 정돈된 배경.
- 인용 50px, 프로필 30px 고정.
- 해당 카드의 주인공인 **게스트의 실제 발언**을 사용한다.
- 하단 프로필: `이름 · 정확한 현재 직함`.
- 하단 공식 TTimes 로고.
- 강조판: 연보라 `#8799FF`, 글씨 딥 네이비 `#07112D`.
- 글자의 실제 바운딩박스 기준으로 상하 여백을 동일하게 둔다.
- 검증 샘플 시작값: 상하 각각 14px, 좌우 각각 23px.
- 강조판끼리 겹치거나 행간을 답답하게 만들지 않는다.

## 4. 검수 게이트

- 모든 카드 1080×1080.
- 표지는 승인된 `_list_` 기반 이미지와 동일한지 확인.
- 본문 순번은 각진 정사각형인지 확인.
- 제목 연보라, 본문 강조판 연보라+딥 네이비 글씨인지 확인.
- 형광펜 높이·상하 여백·가독성 확인.
- 시리즈 배지 없음, 본문 TTimes 로고 없음.
- 마지막 장에만 게스트 프로필과 TTimes 로고.
- 문구·인용부호·숫자·이름·직함·화자 정확성 확인.
- 사진의 자연스러움, 가짜 글자·로고·워터마크, 해부학 오류 확인.
- 독립 vision QA에서 blocking 0일 때만 전달.

## 5. 최종 전달 패키지

완성 후 사용자에게 반드시 다음 순서로 전달한다.

1. 완성된 카드뉴스 이미지 전 장을 `MEDIA:/absolute/path`로 실제 첨부한다.
2. 이미지 경로만 설명하거나 일부 카드만 보내지 않는다.
3. 복사·붙여넣기용 소개문을 별도 코드블록으로 제공한다.
4. 유튜브 링크를 별도 코드블록으로 제공한다.
5. 카드가 5장이 아닐 수 있으므로 실제 완성 장수를 세어 모두 첨부한다.

예시 형식:

```text
MEDIA:/absolute/path/01_cover.png
MEDIA:/absolute/path/02_body.png
...
MEDIA:/absolute/path/NN_closing.png
```

그 뒤:

```text
[소개문]
```

```text
https://youtu.be/VIDEO_ID
```
