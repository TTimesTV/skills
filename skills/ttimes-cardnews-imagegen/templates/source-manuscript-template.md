# TTimes card-news Word manuscript template

Use ordinary Word body paragraphs. Apply **red font** only to the exact phrase intended as the primary design emphasis.

```text
[Optional design-revision notes after the first render]
P15. 그래프 제목을 “...”로 변경
P22. 기존 차트 대신 “...” 차트 사용

[Project title]
2027년 상반기 산업전망

[Subtitle]
AI 투자, 전력, 금리의 새로운 방정식

<1>
독자에게 던지는 첫 질문이나 도입 문장.

질문의 배경과 개인·기업에 미치는 영향을 설명합니다.

<2>
전체 보고서의 핵심 문제를 설명합니다.

이 문장 전체 또는 일부를 Word에서 빨간색으로 지정합니다.

<3> 1. 첫 번째 핵심 변수

첫 번째 장의 도입과 문제를 설명합니다.

<4>
수치·사건·인물 등 한 묶음의 근거를 설명합니다.

다른 독립 주장이 있다면 다음 <N> 블록으로 분리합니다.

<5> 2. 두 번째 핵심 변수

...

<끝>
```

## Writing rules

- `<N>` is a source beat, not a final page number.
- A block should contain one main reasoning beat; the design stage may split it further.
- Red text is exact emphasis authority. Do not use red for deletion or private comments.
- Put post-design changes above `<1>` and start each with `PXX.`.
- Keep sources and figures in the prose or a separate source appendix; never rely on the designer to invent them.
- Use explicit units, periods, subjects, and denominators for statistics.
- Direct quotations must include the speaker and source location in the source ledger.
