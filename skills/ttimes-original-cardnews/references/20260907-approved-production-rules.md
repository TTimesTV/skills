# 2026-09-07 카드뉴스 제작 피드백 정리

## 적용 순서
현재 사용자 지시 > 해당 시리즈 승인본 > 오전/오후 형식 구분 > 범용 디자인 조언. 기존 카드 전체를 새로 설계하지 않는다. 이 문서는 제작 규칙이며 사례 속 뉴스 주장의 사실 검증을 대신하지 않는다.

## 형식부터 고정
- 오전 뉴스형: 새 이슈·정책 중심, 세로 4:5(1024×1280 또는 1080×1350), 실제 사진 중심, 마지막 독자 질문. 맘다니 사례는 사건 자체가 아니라 어린이 AI 금지 대 지도하 활용 교육이라는 토론이 목적이었다. 사건→범위→근거→다른 방식/관점→질문으로 구성한다. 찬반을 기계적으로 같은 분량으로 만들지 않는다.
- 오후 유튜브 요약형: 김덕중·정지훈·박세준 계열, 1080×1080. 사용자 제공 리스트 이미지를 풀프레임 표지로 사용, 실제 발언 인용·형광펜 면 강조·이름/직함으로 마무리. 질문형 결말을 가져오지 않는다.
- 오전 본문의 사진 배치·색감 참고는 오후 표지·비율·마무리까지 바꾸라는 허가가 아니다.
- 원맨·이중학·박영선 등 별도 승인 시리즈는 해당 등록 템플릿을 유지한다. 박세준의 개별 예외를 모든 시리즈에 적용하지 않는다.

## 원고·팩트체크 범위
- 사용자가 팩트체크만 요청하면 주장·원출처·조건·판정만 검증한다. 제목·톤·문체·새 원고 제안을 무단 추가하지 않는다.
- 자기보고와 독립 검증을 구분한다. AI가 기존 연결 도구를 사용한 것과 새로 연결한 것을 구분한다.
- 인용은 실제 음성·자막·화면으로 확인한다. 요약문을 따옴표로 감싸 직접 인용처럼 쓰지 않는다. 의미가 끝나기 전 인용을 끊지 않는다.
- 본문에 ‘박 대표는’ 같은 해설자 소개를 불필요하게 반복하지 않는다.
- LinkedIn 게시글은 짧은 기사체: 사건·핵심 대비·독자 질문. 장황한 교훈·과한 해시태그·제작용 설명은 제외한다.

## 조판·강조
- 한 줄로 들어가는 제목은 한 줄 유지. 의미 없는 강제 두 줄 금지. 폭을 측정하고 줄바꿈을 결정하며, 가독성을 망가뜨릴 정도로 글씨를 줄이지 않는다.
- 사용자가 지정한 따옴표·표현·줄바꿈을 보존한다. 특정 단어 삭제를 전체 제목 재작성으로 확대하지 않는다.
- 뉴스형 본문은 요청 문장 전체에 노란 형광펜 밑줄. 인용 마무리는 해당 승인본의 형광펜 면 강조.
- 사용자가 고른 강조 대상에만 적용한다. 박세준 표지는 ‘GPT의 허깅페이스 침투 사태’이며 ‘페이커’가 아니다.
- 마지막 질문의 두 선택지는 서체·크기·강조 강도를 동등하게. 불필요한 폰트·색·밑줄 변주 금지.
- 기존 텍스트·사진·레이아웃이 잠긴 부분수정은 요청 요소만 바꾼다. 수정 전후 픽셀/텍스트 비교로 영향 범위를 확인한다.

## 사진·권리·게시 지면
- 게시 지면에 ‘자료사진 · 사용자 제공’, 내부 검수 메모, 불필요한 인물 설명을 자동 삽입하지 않는다. 실제 출처가 AFP이면 필요한 크레딧은 ‘출처 : AFP’.
- 사용자가 사진을 준다고 하면 임의 대체 사진 제작/수집을 멈추고 필요한 장면·검색어만 전달한다.
- 사진 출처와 이용권한은 별개. 웹에서 AFP 사진을 찾았거나 출처를 썼다고 상업 사용권이 확보되는 것은 아니다. 취득 경로·권한 확인 상태·촬영 상황은 내부 레저에 남기고 권리 미확인 자산은 게시 가능 판정 금지.
- 자료사진을 사건 현장으로 오인시키는 배치/문구는 피한다. 설명이 꼭 필요하면 사용자와 문구를 확정하거나 오인 없는 자산으로 교체한다.
- 박세준: 2·4장 임의 영상 캡처 거절, 3장 사진만 유지 승인. ‘출처 : TTimes’ 삭제는 이 편의 지시이며 모든 카드의 필수 크레딧 삭제 규칙이 아니다.
- 정적 PNG/JPG만 고집하지 않는다. 내용에 적합하고 권리가 확인된 GIF도 가능. GIF 표지는 텍스트/로고를 고정하고 사진/영상 영역만 움직이는 기존 기준을 따른다.
