# 오전 뉴스형 / 오후 유튜브 요약형 — 사용자 확정 구분

사용자는 두 형식이 다르다는 설명에 ‘그렇지.. 맞아맞아 정확해.!’라고 승인했다. 이후 카드뉴스 제작 전 가장 먼저 이 구분을 확인한다.

## 오전: 뉴스형
- 사례: 맘다니 AI 교육 금지, GPT-6 컴퓨터 사용·영상 편집.
- 새 뉴스·사건을 출처와 근거로 구성한다.
- 해당 승인본은 세로형 4:5, 사진 중심 구성. 이를 2:3이라고 부르지 않는다.
- 마지막은 독자의 의견을 묻는 질문형.

## 오후: 유튜브 요약형
- 사례: 김덕중, 정지훈, 박세준 인터뷰.
- 기존 유튜브 인터뷰를 재가공한다.
- 전체 카드 1080×1080, 1:1 정사각형.
- 표지는 사용자 제공 리스트 이미지가 정사각형 전체를 채운다. 사진 위 하단에 제목, 우상단 로고. 아래에 빈 어두운 공간을 늘려 별도 제목판을 만들지 않는다.
- 마지막은 출연자 실제 발언 인용 + 형광펜 면 강조 + 이름·직함 + 로고. 뉴스형 질문·댓글 요청 결말을 가져오지 않는다.
- 정지훈 승인 원본: PROJECT_ROOT/render_card1.py 및 render_card5.py, delivery/01_cover.png 및 05_closing.png.
- 실제 원본을 열어 비율·폰트·인용 블록·강조 여백·이름/로고 배치를 확인한 뒤 재사용한다. ‘정지훈처럼’이라고 말만 하고 새로운 레이아웃을 설계하지 않는다.

## 이번 박세준 편의 확정 범위
- 오후 유튜브 요약형, 1:1 전체 5장.
- 제목: 해커계의 페이커가 본 / GPT의 허깅페이스 침투 사태.
- 포인트색 강조는 ‘GPT의 허깅페이스 침투 사태’. ‘페이커’가 아님.
- 2~4장만 오전 뉴스형의 사진·본문 구성 느낌을 참고하고 보안 주제의 파스텔 블루그레이·청록 색감을 적용한다. 이것은 표지·전체 화면 비율·마지막 장 형식 변경 승인이 아니다.
- 이전 세로 시안의 색감은 승인. 3장 사진/설명 화면은 사용자가 유지 허용.
- 2·4장의 영상 캡처는 거절, AFP 등 적합한 실제 사진으로 교체 필요.
- ‘출처 : TTimes’ 표기 삭제 지시. 필요 사진 크레딧은 확인된 실제 출처만 넣는다.
- 마지막 장은 정지훈 실제 승인본의 구성으로 복원. 인용문을 단순 자동 줄바꿈해 작은 글 덩어리로 넣는 방식은 거절.

## 금지
- 오전과 오후의 비율·표지·마무리를 혼합하지 않는다.
- ‘색감만 바꾸기’나 ‘본문 느낌 참고’를 새 템플릿 전체 승인으로 확대하지 않는다.
- 자료사진·사용자 제공·내부 검수 메모를 사용자 지시 없이 게시 이미지에 넣지 않는다.
- 현재 박세준 draft_v1은 사용자에게 거절된 비율/표지/마무리 시안이다. 기본 템플릿이나 최종본으로 승격하지 않는다.
