# 종이 질감·움직이는 표지 — 2026-09-06

사용자 확정 방향: 사진 반·텍스트 반의 고정 구조 유지. 백색에 가까운 종이결, 먹색 글자, 절제된 노랑 강조로 차별화한다. 매 장 다른 구조로 바꾸지 않는다. Vox의 로고나 특정 지면을 복제하는 뜻이 아니다.

납품: PDF 불필요. 요청 시 실제 GIF 표지를 만들고, 채팅 재생용 MP4와 정적 표지를 추가로 제공할 수 있다.

이번 구현:
- PNG 6장, 1080×1350. 본문 사진 영역은 1080×675.
- 고정 시드의 미세한 종이결. 애니메이션에서 종이·글자가 깜빡이지 않음.
- 표지는 제목·우측 로고만. 본문 우측에는 `출처 : AFP`만.
- 4초 루프. 사진만 약하게 확대·복귀하고 제목·로고는 고정. 인물의 입·표정은 합성하지 않음.
- GIF 720×900. 같은 연속 프레임이 합쳐져 인코딩 프레임은 39개, 총 재생시간은 4초 유지.
- MP4는 GIF의 제한된 팔레트를 거치지 않고 원색 RGB 프레임에서 직접 인코딩.
- 로컬 파일·프레임 검증과 실제 게시 플랫폼에서의 혼합 이미지 재생 검증은 별개.

원고는 이전 검증된 6장 내용 유지. 정책·연구·사진 전체 출처는 ZIP의 sources.json. 이번 결과는 디자인 후보이며 아직 사용자 최종 승인은 아니다.
