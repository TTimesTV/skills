# TTimes 기사·헤드라인 선정

## Overview

티타임즈 원고의 주장에 붙일 기사와 헤드라인을 고르는 절차다. 목표는 관련 기사를 많이 모으는 것이 아니라, 시청자가 헤드라인만 봐도 해당 발언의 핵심을 즉시 이해하고 납득할 수 있는 **최적의 증거 기사 1개 또는 균형 잡힌 기사 묶음**을 고르는 것이다.

기사 선정은 단순 키워드 일치가 아니다. 발언의 주체·행동·적용 범위·실행 단계·인과관계를 분해하고, 그중 화면에서 입증해야 할 주장과 가장 정확히 맞는 헤드라인을 선택한다.

## When to Use

- 사용자가 `이 말에 붙일 기사`, `기사 헤드라인`, `기사 찾아줘`, `자료화면용 기사`를 요청할 때
- 티타임즈 원고나 컷본의 특정 발언을 기사로 뒷받침할 때
- 두 기업·두 사례를 기사 헤드라인으로 나란히 보여줄 때
- 화면구성 문서에 기사 제목·언론사·날짜·링크를 넣을 때

티타임즈와 무관한 일반 기사 검색은 사용자의 일반 검색 지시를 우선한다. 요청이 모호하면 대화 맥락·원고·자막 작업 여부로 티타임즈 업무인지 먼저 판별한다.

## Core Principle: 관련성보다 입증력

항상 다음 질문부터 답한다.

> 이 헤드라인이 원고의 어떤 주장을, 화면을 스쳐 보는 시청자에게 직접 증명하는가?

예를 들어 원고가 `삼성전자와 SK하이닉스도 AI를 실제로 사용해야 반도체의 효율성을 입증할 수 있다`고 말한다면:

- `삼성전자, 챗GPT 전사 도입`은 회사의 AI 사용은 입증하지만 반도체·제조 현장과의 연결은 약하다.
- `삼성전자 반도체 공정에 AI 활용`은 주체·산업·행동이 모두 맞아 더 강하다.
- `하이닉스 반도체 팹에 디지털트윈 구축`은 SK하이닉스 제조 현장에서 AI 기반 기술을 실제 적용한다는 것을 보여준다.

따라서 이 경우에는 사무용 AI 도입 기사보다 **반도체 제조 현장의 AI 적용 기사 두 개를 짝으로 선택**한다.

## Workflow

### 1. 티타임즈 업무 여부 판별

다음 중 하나면 티타임즈 기사 선정 규칙을 적용한다.

- 원고·화자·타임코드·강조자막·설명자막이 함께 제공됨
- 사용자가 `기사 헤드라인`, `첨부`, `자료`, `화면`이라고 표현함
- 현재 대화가 티타임즈 영상 제작 흐름임

완료 기준: 요청을 일반 정보 검색과 화면 증거 선정 중 하나로 분류한다.

### 2. 입증할 발언을 한 문장으로 고정

원고에서 다음 다섯 요소를 추출한다.

```text
주체 : 누가
행동 : 무엇을 했는가
대상·현장 : 어디에 적용했는가
실행 단계 : 검토·계획·시범·도입·운영 중 무엇인가
의미 : 이 사례로 무엇을 증명하려는가
```

예시:

```text
주체 : 삼성전자·SK하이닉스
행동 : AI를 실제 생산 현장에 적용
대상·현장 : 반도체 공정·팹
실행 단계 : 구축·활용
의미 : AI 반도체 공급사도 AI의 생산성 효과를 직접 입증 중
```

완료 기준: 검색어가 아니라 검증 가능한 주장 한 문장으로 정리된다.

### 3. 기사 매체 우선순위 적용

티타임즈 첨부 기사는 다음 순서로 찾는다.

1. 머니투데이
2. 뉴스1
3. 뉴시스
4. 지디넷코리아
5. 위 매체에 적합한 기사가 없으면 공신력 높은 해외 경제지·통신사
   - Reuters, Bloomberg, Financial Times, The Wall Street Journal, CNBC 등
6. 그다음 국내 주요 종합지·경제지·방송사
   - SBS, KBS, MBC, 조선일보, 중앙일보, 한겨레, 동아일보
   - 아시아경제, 서울경제, 문화일보, 한국일보 등
   - 위 목록은 예시이며 매체를 제한하는 폐쇄형 목록이 아니다. 기사 신뢰도와 원고 입증력이 충분한 다른 국내 언론도 사용할 수 있다.
7. 연합뉴스는 티타임즈 첨부 기사에서 제외

사용자가 특정 기사나 매체를 지정하면 사용자 지정 원문이 이 순서보다 우선한다. 공식 공시·회사 발표·정부 문서는 팩트체크에 활용할 수 있지만, 기사 첨부물은 위 우선순위에 따라 고른다.

완료 기준: 선택 기사가 허용 매체이며, 더 높은 우선순위 매체에 동등하거나 더 강한 기사가 없는지 확인한다.

### 4. 빠른 검색과 원문 확인

- 우선 매체 네 곳을 병렬 검색한다.
- 검색 결과 제목만으로 최종 선정하지 않는다.
- 원문을 열어 제목·언론사·게시일·수정일·본문의 실제 적용 범위를 확인한다.
- 포털 재전송 페이지와 Google News 중계 링크가 아니라 언론사 직접 URL을 확보한다.
- 적합한 기사 1개가 기준을 통과하면 불필요하게 수십 건을 더 조사하지 않는다.

완료 기준: 언론사 직접 링크가 열리고, 본문이 헤드라인의 주장을 실제로 뒷받침한다.

### 5. 실행 단계 강도 판정

헤드라인의 증거 강도는 다음 순서다.

```text
실제 운영·활용·구축 완료
> 공식 도입·전사 확대
> 현장 실증·PoC
> 도입 계획·추진
> 검토·협의
> 제휴·비전 발표
```

원고가 현재 사용 사실을 주장하는데 `검토`, `추진`, `파트너십` 기사만 붙이면 안 된다. 단, 기사 제목의 주체가 제3자라도 본문과 제목에 적용 현장이 명시되면 사용할 수 있다. 예: `SKT, ... 하이닉스 반도체 팹에 디지털트윈 구축`은 SKT가 구축 주체지만 하이닉스 팹의 실제 적용을 입증한다.

완료 기준: 원고의 시제와 기사 실행 단계가 일치한다.

### 6. 후보 점수화

후보마다 0~2점으로 평가한다.

| 기준 | 0점 | 1점 | 2점 |
|---|---|---|---|
| 주체 일치 | 다른 주체 | 그룹·관계사 | 정확한 기업·인물 |
| 행동 일치 | 관련 없음 | 간접 관련 | 발언 속 행동 그대로 |
| 현장·범위 | 다른 분야 | 회사 전체의 일반 사례 | 원고의 구체적 업무·공정 |
| 실행 단계 | 검토·전망 | 계획·실증 | 실제 도입·운영·구축 |
| 헤드라인 명료성 | 본문을 읽어야 이해 | 일부 전달 | 제목만으로 증명 |
| 매체 우선순위 | 후순위·비허용 | 허용 매체 | 최우선 매체 |
| 시점 적합성 | 낡아 현재와 불일치 | 과거지만 유효 | 최신이면서 유효 |

**선정 원칙:** 총점이 높은 기사 중, 주체·행동·실행 단계에서 0점이 없는 기사를 선택한다. 최신 기사라는 이유만으로 입증력이 낮은 기사를 고르지 않는다.

### 7. 복수 기사 짝 맞추기

두 기업이나 사례를 나란히 보여줄 때는 각 기사의 개별 점수뿐 아니라 **대칭성**을 평가한다.

좋은 짝:

```text
삼성전자 반도체 공정의 AI 활용
SK하이닉스 반도체 팹의 디지털트윈 구축
```

나쁜 짝:

```text
삼성전자 전사 챗GPT 도입
SK하이닉스 AI 반도체 매출 전망
```

좋은 짝은 다음이 비슷하다.

- 같은 산업 층위: 제조↔제조, 사무업무↔사무업무
- 같은 실행 강도: 활용↔구축, 계획↔계획
- 같은 증명 목적: 생산성↔생산성, 투자↔투자
- 비슷한 헤드라인 가독성

완료 기준: 두 기사를 바꿔 붙여도 같은 비교 축이 유지된다.

### 8. 화면 적합성 판정

기사 본문이 훌륭해도 헤드라인이 화면에서 약하면 다른 기사를 선택할 수 있다.

선호:

- 기업명과 핵심 행동이 제목 앞부분에 있음
- `AI 활용`, `도입`, `구축`, `생산성`, `공정`, `팹`처럼 장면의 핵심 단어가 보임
- 제목 일부를 잘라도 의미가 유지됨
- 두 기사 헤드라인을 나란히 놓았을 때 비교가 즉시 됨

회피:

- `왜?`, `무슨 일?`, `업계 주목` 등 클릭 유도형 제목
- 주체가 제목에 없는 기사
- 원고보다 강한 단정
- 너무 긴 부제 없이는 의미가 성립하지 않는 기사

완료 기준: 시청자가 본문 없이 헤드라인만 보고 원고와의 연결을 이해할 수 있다.

## Output Format

사용자가 기사를 요청하면 가장 적합한 결과를 먼저 복붙 가능한 코드블록으로 제공한다. 설명은 코드블록 뒤에 짧게 붙인다.

```text
//기사 헤드라인 2분할

기사 제목
언론사 | YYYY.MM.DD
언론사 직접 URL

기사 제목
언론사 | YYYY.MM.DD
언론사 직접 URL
```

필요한 경우에만 다음을 덧붙인다.

```text
사용 구간 :
입증하는 주장 :
선정 이유 :
주의사항 :
```

후보를 여러 개 나열하지 말고 최적안 1개 또는 최적 조합 1개를 먼저 제시한다. 사용자가 대안을 요구할 때만 2순위 후보를 추가한다.

## Gold Example

원고:

```text
효율성을 본인 스스로 입증하지 않으면 반도체를 어떻게 팔아요?
SK하이닉스가 자기네들은 AI 안 쓰면서 AI 반도체 판다는 게 말이 돼요?
```

최종 선정 방향:

```text
삼성전자 반도체 공정에 AI 활용…“효율·품질 극대화”

SKT, 엔비디아 GTC서 AI 파트너로 소개…하이닉스 반도체 팹에 ‘디지털트윈’ 구축
```

선정 이유:

- 두 기사 모두 일반 사무용 AI가 아니라 반도체 제조 현장을 다룬다.
- `활용`과 `구축`이라는 실행 동사가 있어 단순 검토보다 강하다.
- 삼성전자와 SK하이닉스가 AI의 생산성 가치를 제조 현장에서 실증한다는 원고 논리에 맞는다.
- 두 헤드라인을 나란히 놓았을 때 `반도체 공정 AI`와 `반도체 팹 디지털트윈`이 시각적으로 대칭을 이룬다.

## Common Pitfalls

1. **키워드만 맞는 최신 기사 선택**
   - 최신성보다 주장 입증력과 실행 단계를 우선한다.

2. **계획을 실제 사용으로 둔갑**
   - `검토`, `추진`, `예정`을 `사용 중`의 근거로 쓰지 않는다.

3. **비교 축이 다른 기사 두 개 배치**
   - 제조 현장 주장에는 제조 현장 기사끼리 맞춘다.

4. **우선 매체를 찾았지만 더 약한 기사 선택**
   - 매체 순위는 품질 필터 뒤의 우선순위다. 우선 매체라도 발언을 입증하지 못하면 다음 매체로 내려간다.

5. **검색 중계 URL 전달**
   - 언론사 직접 URL을 확보한다.

6. **기사 제목을 임의로 고침**
   - 기사 헤드라인은 원문 그대로 보존한다. 화면용 요약 문구가 필요하면 별도 자막으로 작성한다.

7. **연합뉴스 첨부**
   - 발견용으로 보더라도 티타임즈 최종 첨부 기사에서는 제외한다.

8. **과잉 조사로 지연**
   - 기준을 통과하는 최적 후보가 나오면 먼저 전달하고, 심층 교차검증은 주장 위험도가 높거나 사용자가 요청할 때 수행한다.

## Verification Checklist

- [ ] 티타임즈 업무 여부를 먼저 판별했다.
- [ ] 원고에서 주체·행동·현장·실행 단계·의미를 추출했다.
- [ ] 사용자 지정 기사와 매체 우선순위를 지켰다.
- [ ] 연합뉴스를 최종 첨부에서 제외했다.
- [ ] 기사 원문과 언론사 직접 URL을 확인했다.
- [ ] 원고의 시제와 기사의 실행 단계가 일치한다.
- [ ] 헤드라인만으로 원고의 주장이 이해된다.
- [ ] 복수 기사라면 산업 층위와 실행 강도가 대칭이다.
- [ ] 기사 제목을 임의로 수정하지 않았다.
- [ ] 최적안부터 복붙 가능한 코드블록으로 제공했다.
