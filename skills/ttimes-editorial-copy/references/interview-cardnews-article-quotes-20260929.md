# 인터뷰 카드뉴스: 기사체 + 실제 발언 인용

## 적용 범위와 우선순위

2026-09-29 사용자가 강수진 카드뉴스 기사체 수정본을 선택한 뒤 “앞으로 내가 주면 그냥 대충 기사체로 하고 따옴표”라고 기본값을 지정하고 스킬 반영을 요청했다. 이후 사용자가 제공하는 인터뷰·유튜브 발언 기반 카드뉴스에 적용한다. 새 뉴스 발제형, 일반 자막, 업로드 설명에는 자동 확대하지 않는다. 현재 회차의 명시 지시가 최우선이다.

이 범위에서는 과거의 ‘출연자 이름을 넣지 않는다’, ‘기사체를 피한다’, ‘마지막도 본문과 같은 장표로 만든다’는 선호보다 이 규칙이 우선한다. 기존 승인 시리즈의 시각 템플릿까지 바꾸라는 뜻은 아니다.

## 기본 구성

- 본문: 출연자가 설명한 내용을 읽기 쉬운 기사체로 정리하고, 핵심 실제 발언을 “ ”로 인용한다. `강수진 박사는 …라고 설명합니다.`, `강 박사는 “…”라고 말합니다.`처럼 발언 주체를 드러낸다. 매 문장마다 이름을 반복할 필요는 없다.
- 출연자의 경험은 경험으로, 조건부 주장은 조건부로 쓴다. 체험담을 보편적 효과나 검증된 사실로 바꾸지 않는다.
- 두 문단 등 해당 시리즈의 승인된 본문 밀도·구조는 유지한다. ‘대충 기사체’는 빠르고 자연스럽게 정리하라는 뜻이지 출처 검증을 생략하라는 뜻이 아니다.
- 마지막 장: 설명형 본문을 끝까지 이어 붙이지 않고 **출연자 발언 인용문 + 이름·직함**으로 마무리한다. 표지의 주제를 회수하는 실제 발언을 고르고, 승인된 인용 마무리 배경·형광펜·로고 문법을 재사용한다. 회차별 다른 결말을 명시하면 그 지시를 따른다.

## 발언 범위 및 인용 정확성

- 본문에도 출연자가 말하지 않은 실무 조언, 예시, 논리적 확장, 모델의 결론을 덧붙이지 않는다. 그럴듯한 부연도 별도 허가 없이는 제외한다.
- 진행자 설명·질문을 출연자 발언으로 합치지 않는다. 직접 인용뿐 아니라 이름을 붙인 기사체 요약에도 화자 확인이 필요하다.
- 따옴표 안에는 확인된 실제 발언만 둔다. 요약·새 연결문·번역한 전문용어를 넣고 직접 인용이라고 부르지 않는다. 군더더기 제거 등 편집 인용이 필요하면 의미·조건·말투를 보존하고 편집 범위와 원문을 내부 원장에 남긴다. 대폭 윤문은 따옴표 밖 간접화법으로 처리한다.
- 인용 후보마다 영상 URL, 시작·종료 시각, 원문, 화자 근거를 보존한다. 화자 없는 자동자막의 문맥만으로 화자를 확정하지 않는다. 원음/영상 또는 화자 표시된 권위본으로 확인한다. 오류·누락이 의심되는 자동자막을 조용히 고쳐 확정 인용으로 내지 않는다.
- 시안 승인과 원음·화자 검증은 별개다. 미확인 인용을 사용자가 시안으로 요청한 경우 검증 상태를 분리해 알리고, 게시용 최종 검증 완료로 표시하지 않는다.

## 이번 교정에서 배울 것

‘과한 열정’이라는 경험담에서 `어디서 멈출지 알려줘라`, `디자인과 부가 기능을 제한하라`는 조언을 만들어 붙인 것은 발언 발췌가 아니다. 실제로 말한 입력 자료·대화 기록·출력 분량 조절, 비용 역전, 에이전트 생성 승인 등의 구간을 근거로 구성해야 한다. 특정 회차의 용어·표지·정확히 5장이라는 수는 다음 회차에 강제하지 않는다.
