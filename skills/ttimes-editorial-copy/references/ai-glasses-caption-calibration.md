# AI-glasses optical and product caption calibration

Use this reference only when AI glasses, XR glasses, displays, birdbath optics, waveguides, or Project Aura appear in source speech. It records terminology and caption-risk lessons, not a complete hardware fact sheet.

## Layer map

```text
display source / microdisplay
→ optical engine
→ optical delivery structure
→ visible virtual image
→ device thickness, weight, brightness, field of view, and comfort
```

Do not treat these layers as synonyms.

## Terms

### Micro-OLED

A small high-pixel-density OLED display used as an image source in many near-eye systems. Its presence alone does not determine the device's optical structure or comfort.

### Birdbath optics

A near-eye optical structure that reflects and magnifies a microdisplay image toward the eye. It can provide a large visible image but usually requires a more visibly protruding optical module than ordinary eyewear.

Safe explainer:

```text
버드배스(Birdbath) : 디스플레이 영상을 반사·확대해 눈앞에 가상 화면으로 보여주는 광학 구조
```

### Waveguide

An optical structure that couples light into a lens-like guide and delivers it toward the eye. `렌즈 내부로 영상을 전달한다` is safer than saying the micro-OLED panel itself is embedded throughout the lens.

### Luminance

Safe explainer:

```text
휘도(輝度) : 화면이나 광원이 특정 방향으로 얼마나 밝게 보이는지를 나타내는 수치
```

## Caption boundaries

- `same display` does not imply `same wearing experience`
- `lens implementation` does not necessarily mean the display panel is physically in the lens
- `smaller and lighter` should modify the device/form factor, not the screen, unless the source explicitly describes screen size
- manufacturing speed, yield, comfort, and optical quality are independent axes
- company strategy inferred by a speaker must remain an inference, not be converted into an official declaration

## Project Aura language

Project Aura should be described as an XREAL hardware project involving Google's Android XR/Gemini platform and Qualcomm technology, not simply as a Google-manufactured pair of glasses.

When speech contrasts Project Aura with ordinary AI glasses, preserve the actual judgment:

```text
콘텐츠가 아직 부족한 프로젝트 아우라
일상형 AI 안경보다 VR에 가까운 경험
```

This is a speaker's present-experience assessment, not a permanent product-category verdict.

## Response-mode reminder

If the PD asks `무슨 말`, explain these distinctions. If the PD then asks `강조자막`, stop explaining and return only the caption code block.
