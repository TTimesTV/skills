# 콘텐츠 다층 분류와 조건별 화면 선택

2026-10-13 사용자 요청: 진행자·게스트·주제 등 여러 계위로 콘텐츠를 분석해 화면구성 학습에 사용한다. 이 문서는 관찰 가능한 편집 행동의 분류 기준이다. 인물의 고정 성격, 통계적 인과, 영상 성과를 추정하는 규칙이 아니다.

## 근거와 적용 범위

작업 근거: `LOCAL_REFERENCE_NOT_DISTRIBUTED`의 `source_inventory.json`, `corpora.json`, `reviewed_cases.json`, `cross_episode_cases.json`.

강정수 1편(1-1·1-2 분할은 한 편)과 2편, 박종천 1·2편, 이제현, 임승찬·윤우진 정본의 6개 편집 단위를 비교했다. 강정수 실제 초안-최종 대응 42사례와 추가 12개 문맥 사례를 검토했다. 후자는 모두 같은 정밀도의 초안-최종 대응 쌍은 아니다. 진행자 홍재의는 여러 게스트와 비교할 수 있지만 이재원은 이 집합에서 강정수와만 연결된다. 진행자 효과와 게스트·주제 효과를 분리해 순위를 매길 근거는 없다.

강정수 2편 10/8 JSON은 10/7과 원고·선택 항목이 같고 후속 revision 36건 등이 추가된 버전이다. 대부분 말자막·오인식·문법 교정이며 자료 취향 변화 36건으로 세지 않는다. `completed` 표기만으로 영상 반영을 독립 검증했다고 하지 않는다. 이제현·박종천은 이전 감사된 추출과 비교 기록을 재사용했고 임승찬·윤우진은 gold DOCX의 실제 run 서식을 읽었다. 새 영상 전편 검토는 하지 않았다. 이전 영상 표본 관찰은 기존 참고서에 기록된 범위만 인정한다.

## 기록 단위

회차 카드에는 진행자, 게스트, 회차·시리즈, 주요 주제, 제작 단계와 출처를 남긴다. 구간 카드에는 다음을 독립적으로 기록한다.

1. 주제: 조직·교육·리더십 / 기술 원리 / 제품 사용 / 산업·시장 / 리터러시 등 복수 허용.
2. 실제 발화자와 대화 역할: 질문 설정, 재질문, 재진술, 비유 제공, 반응, 근거 범위 한정, 사례 연결, 주제 전환. 게스트도 질문할 수 있다.
3. 게스트 발화 방식: 정의, 원리·단계, 직접 체험, 실패·고백, 수치·근거, 인과·전망, 비교·비유. 개인 이름을 방식의 대용으로 쓰지 않는다.
4. 자료 기능: 식별, 입증, 관계·순서 설명, 시연, 상황 재구성, 예시. 자료 없음과 미확정은 구분한다.
5. 자막 기능: 정의, 인과·결론, 비교, 반응·대사, 질문·소제목, 수치, 교정, 식별. 기사 번역·그래픽 라벨과 독립 편집자막도 구분한다.
6. 시청자 상태와 전개: 첫 소개/이미 설명됨, 현재 질문과의 연결, 등장→추가/교체→유지/재사용→종료. 앞뒤 구간의 읽기 부담을 함께 본다.
7. 제작 조건: 원본 발화 컷, 자료 확보, 문구 수정, 앵커 변경, 화면 구현 변경을 분리한다.

주제나 인물 하나로 자료 종류·자막 길이를 자동 결정하지 않는다. 우선 현재 구간에서 해결할 이해 문제를 고르고, 실제 대화의 역할과 자료 확보 상태로 선택을 보정한다.

## 선택을 바꾸는 관찰

- 진행자도 자막 원천이다. 박종천 2편 원고 36:06의 홍재의 발화가 최종 ‘GPU 도매에서 소매까지 진출’에 연결된다. 임승찬·윤우진 P324–330에서는 진행자가 취소 원인을 재진술하는 발화에 ‘비 때문에 생겼던 취소 문제’가 붙는다. 게스트 말만 요약하면 이런 순간을 놓친다.
- 낯선 대상을 묻는 질문은 식별·정의가 필요한 신호다. 임승찬·윤우진 P30–36의 ‘튜링이 뭐 하는 데냐’ 다음 설명자막처럼 조직 인터뷰에도 충분한 정의를 쓴다. 반대로 이름을 이미 아는 대상마다 서비스 설명을 반복하지 않는다.
- 같은 사람 안에서 방식이 바뀐다. 강정수 체험에서는 연결 화면과 비서 말풍선(C05–C07), 산업 분석에서는 기사·수익 구조(C25–C32), 기술 설명에서는 VM 정의·단계 그래픽(C38–C40)을 썼다. ‘강정수형 화면’ 하나로 고정하지 않는다.
- 조직 콘텐츠에도 실자료와 수치가 필요하다. 임승찬·윤우진 P279의 실제 서비스, P313–320의 취소율은 인물 중심 기본값의 예외다. 추상어가 나왔다는 이유만으로 구조도를 만드는 것과 실제 설명 필요를 구별한다.
- 같은 조직 회차에서 코치의 개념화와 운영자의 체험이 교차한다. 윤우진의 선장 비유(P200–203)는 자기고백·반응을, 임승찬의 전략 설명(P357–396)은 질문·정의·비교의 순서를 살린다. 이를 두 사람의 모든 회차 성향으로 확장하지 않는다.
- 시연·상황 재구성·입증은 다르다. 강정수 C06의 캐릭터 말풍선은 체험 재구성이며 실제 동작 시연이나 사실 입증이 아니다. 제목만 맞는 영상·인물 장면을 입증으로 분류하지 않는다.
- 자료가 확보되어 초안의 도식이 원본 표로 바뀐 사례는 취향 변화와 분리한다. 박종천 2편의 지출 비중 자료는 출연자의 추정이라는 대화상의 한정도 함께 유지한다.
- JEV는 초벌 보조다. 이번 42사례에서 자료 없는 강조 문구를 시연·입증으로, 캐릭터를 실제 시연으로 분류한 오류를 직접 교정했다. 각 축에 없음/복합/미확정을 제공하고 최종 지시를 직접 대조한다. 확률값은 증거 강도가 아니다.

## 발화 범위에 대한 명시적 사용자 교정

김지현·정도희 1편의 2026-10-13 사용자 피드백: 짧은 검색 단어에만 하이라이트를 붙여 실제 싱크를 고려하지 않은 화면구성을 수정하도록 요청했다. 적용 범위는 검색 앵커가 아니라 실제 화면의 등장부터 의미상 종료까지 선택한다. 발화 전부를 무조건 길게 칠하라는 규칙은 아니다. 결론 절만 필요한 사례는 좁게, 단계별 추가·교체가 필요한 설명은 구간과 변화를 나눠 기록한다. 실제 수정 28곳은 `work/kim_screen_ranges_20261013/ranges.json` 및 `word_check.json`에 보존돼 있다. 이 피드백은 최종 JSON 비교와 별도 근거다.

## 누적할 때 확인할 것

한 사례는 조건부 참고, 반복된 선택은 잠정 기준, 명시적 사용자 교정은 그 적용 범위 안에서 우선 기준으로 둔다. 이후 반례는 기존 규칙의 조건을 수정하는 데 사용한다. 같은 진행자·다른 게스트, 같은 게스트·다른 주제, 같은 주제·다른 조합을 비교하되 표본이 없는 조합은 미확정으로 남긴다. 회차 길이·분할 방식·혼합 항목 수로 자막 밀도나 채택률을 계산하지 않는다. 성과 데이터 없이 클릭률·이탈률·이해도 개선을 주장하지 않는다.
