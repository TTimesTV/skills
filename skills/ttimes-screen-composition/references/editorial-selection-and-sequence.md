# 발화별 화면 선택과 설명 누적

상태: 2026-09-06 운영 보강. 사용자에게 승인받은 개별 구성안을 대체하지 않으며, 아래 예시는 판단 연습이지 정답 코퍼스가 아니다.

## 1. 먼저 내용 단위로 읽는다

입력은 승인된 컷 원고다. 문장마다 자동으로 하나씩 지시를 붙이지 않는다. 질문→답변, 원인→결과, 비교→판정 등 의미가 완성되는 단위로 묶고, 이전 설명과 다음 문장까지 읽는다.

각 단위에서 먼저 판단할 것:
- 시청자는 이미 무엇을 아는가?
- 지금 새롭게 알아야 하거나 느껴야 하는 것은 무엇인가?
- 발화와 얼굴만으로 그것이 전달되는가?
- 도구를 추가하면 무엇이 더 명확해지는가? 오히려 무엇을 가리는가?

## 2. 선택은 ‘유형 분류’가 아니라 대안 비교다

애매하거나 중요한 지점에서는 `인물 유지`를 포함한 유력 대안을 비교한다. 모든 문장에 긴 대안표를 만들지는 않는다.

| 발화가 요구하는 일 | 먼저 비교할 수단 | 배제할 선택 |
|---|---|---|
| 낯선 대상의 정체 파악 | 인물/제품 실물+짧은 라벨, C4 정의 | 처음 등장한 모든 명사에 자동 정의 |
| 실제 동작·장소·현장 이해 | 해당 동작이 보이는 영상 | 이름만 같은 기업 홍보 영상 |
| 내부 위치·흐름·작동 이해 | 주석 자료, 최소 도해, C4/C5 | 보이지 않는 원리를 일반 공장 영상으로 대체 |
| 수치의 차이·규모 파악 | 동일 기준 비교, 필요한 데이터만 재구성 | 단위·분모 없는 큰 숫자 |
| 여러 관계를 동시에 기억 | C5 구조판, 비교축, 단계 | 병렬 항목을 인과 화살표로 연결 |
| 선명한 판정·반전·감정 | 얼굴 유지 또는 C2 강조 | 모든 결론을 보고서식 제목으로 재작성 |
| 앞 설명의 단순 반복 | 생략, 기존 도해 재사용, 해당 부분만 강조 | 동일 정의·자료를 매번 처음부터 재등장 |

‘낯선 용어니까 설명’, ‘중요하니까 강조’에서 멈추지 않는다. **이 문장에서 이 수단이 더 나은 이유**를 정한다. 예컨대 위치 차이가 논점이면 정의의 길이보다 옆/위의 위치가 보이는 비교가 우선일 수 있다.

## 3. 내부 선택 기록은 짧고 검토 가능하게

기존 segment의 speech_anchor/editorial_goal/visual_need/visual/editorial_captions를 재사용한다. 선택 기록에는 필요한 경우만 다음을 추가한다:
- viewer_gap: 발화·기본 화면만으로 남는 구체적 이해 공백 또는 필요한 정서 효과
- chosen_reason: 선택한 수단이 그 공백을 해결하는 방식
- rejected_alternative: 가장 유력한 다른 수단을 쓰지 않은 이유
- omission_cost: 빼면 실제로 잃는 것; 잃는 것이 없으면 NONE을 우선

최종 Word에는 이 메타데이터를 반복 출력하지 않는다. 사용자가 요구한 경우에만 실제 Word 코멘트나 별도 검토표로 전달한다.

## 4. 어디서 넣고 빼는가

- IN: 질문의 축을 고정해야 하는 시작, 대상이 특정되는 발화, 비교가 시작되는 발화 등 **의미가 연결되는 실제 구절**로 지정한다.
- 강조를 너무 일찍 보여줘 다음 발화의 반전을 스포일러하지 않는다.
- 자료의 출처 원본 시각과 편집본의 발화 IN/OUT을 별개로 관리한다.
- 변화: 같은 도해의 A→B 설명이면 새 화면보다 해당 부위 강조/라벨 교체를 먼저 검토한다.
- OUT: 해당 이해 과제가 끝나는 실제 구절. 다음 무관한 주장까지 근거 화면을 끌고 가지 않는다.
- 자료와 강조자막은 독립적으로 종료할 수 있다. 강조가 끝나고 자료만 남으면 말자막 복귀를 확인한다.
- 시간이 없는 원고에는 정확한 구절 앵커를 사용한다. 초 단위 시각을 만들어내지 않는다. 실제 미디어가 있으면 앵커와 음성을 대조한다.
- 읽을 시간이 부족하면 의미 단위를 다시 묶거나 표현 수단을 바꾼다. 초당 글자 수만으로 무조건 늘이지 않는다.

## 5. 긴 영상에서 설명을 쌓는 법

필요한 개념만 concept ledger로 추적한다. 모든 명사를 등록하지 않는다.

- introduced_at: 처음 정체를 밝혀 준 구간
- established: 시청자에게 이미 설명한 범위
- unresolved: 아직 설명하지 않은 작동·비교·함의
- visual_asset: 재사용 가능한 도해/자료 ID
- next_use: 재사용/확장/짧게 상기/종료 중 하나

새 단위마다 확인:
1. 새 정의인가, 이전 정의의 적용인가? 적용이면 다시 정의하지 않는다.
2. 관계의 새 부분을 더하는가? 기존 도해에 확장하거나 발화 부위만 강조할 수 있는가?
3. 새로운 비교축·단위·전제가 생겼는가? 그렇다면 이전 도해를 무리하게 재활용하지 않는다.
4. 앞 강조와 같은 결론인가? 반복이라면 생략하고, 새 조건·대가·반론이 붙었다면 차이를 드러낸다.
5. 긴 간격이나 주제 전환 때문에 상기가 필요한가? 고정된 시간 간격이 아니라 의존 관계로 판단한다.
6. 여러 시각 과제가 연속되면 얼굴과 말자막으로 돌아올 수 있는 자연스러운 지점이 있는가?

화면 전환 횟수나 자막 개수 목표를 만들지 않는다. 누적 설명은 장면을 많이 넣는다는 뜻이 아니다.

## 6. 짧은 연습 예시 — 승인 정답 아님

### 위치 비교
가정 발화: ‘기존에는 메모리를 연산 칩 옆에 놓았는데, 새 방식은 위에 쌓습니다.’
- 문제: 명칭보다 위치 차이를 이해해야 한다.
- 후보: 옆/위가 보이는 동일 시점 비교 도해 + 짧은 라벨.
- 배제: 적층이라는 말만 있는 공장 B-roll, 이미 보여 주는 차이를 장문 자막으로 재설명.
- IN/변화/OUT: ‘기존에는’에서 기존 위치 → ‘위에’에서 새 위치 강조 → 위치 설명이 끝나면 종료 또는 다음 논점에 필요한 도해만 유지.
- 주의: 특정 제품 사실로 사용하려면 원출처 검증이 별도로 필요하다.

### 화자가 판단을 유보
가정 발화: ‘가능성은 있지만 아직 어떤 방식이 이길지는 모르겠습니다.’
- 후보: 얼굴과 말자막 유지.
- 배제: ‘승자는 새로운 메모리’ 같은 확정 강조; 주저하는 표정을 가리는 일반 자료.
- NONE 이유: 별도 자막이 불확실성을 지우거나 과도한 판정을 만들 수 있다.

### 기존 구조 재사용
앞에서 구성 요소 A/B를 설명했고 지금은 B의 역할만 비교한다면, 전체 정의를 새로 띄우기보다 기존 구조의 B만 강조하는 안을 검토한다. 구성 요소의 전제가 달라졌으면 새 도해가 맞다.

## 7. 통합 검토

기존 과소시각화/과잉장식/구성·근거 검토에 다음을 함께 적용한다:
- 선택의 필요성뿐 아니라 **이웃 구간보다 이 구절에 놓은 이유**가 명확한가?
- 이미 설명한 것을 새것처럼 반복하지 않았는가?
- 관계의 변화가 없는 자막 교체를 남발하지 않았는가?
- 얼굴을 유지해야 할 유보·감정·반응 구간을 자료가 덮지 않았는가?
- 자료로 보이는 사실과 발화의 주장이 같은 범위인가?
- 기획자는 핵심 관계·문구·의미상 타이밍을 고정하고, 의미를 바꾸지 않는 폰트·색·세부 모션은 디자이너 재량으로 남겼는가?

통과는 ‘검토 가능한 구성안’이라는 뜻이다. 사용자 승인이나 새 원고에 대한 판단 성능이 자동 증명되는 것은 아니다.
