# 박종천 1편 화면 구성 실시간 피드백

2026-09-16. 사용자는 구성안을 한 대목씩 보며 자신이라면 어떻게 했을지 피드백하고, 그 판단을 이후 작업에 반영하기를 요청했다. 개별 확정 항목만 기록한다. 아직 검토하지 않은 조수의 초안 전체를 승인본으로 취급하지 않는다.

## 01 기존 출연자의 프로필 카드

- 조수 초안: 이름·현 직함과 CAIO의 뜻만 짧게 표시.
- 사용자 피드백: 박종천의 기존 프로필 이미지를 제공하며 “티타임즈에 나온 사람들은 이런식으로 해서 주면 좋을 것 같기는 해”라고 설명.
- 이번 인물의 기준 자료: [사용자 제공 프로필 이미지](../assets/park-jongcheon-feedback/profile-user-reference.png).
- 적용 선호: 티타임즈 기존 출연자를 소개할 때는 기존 방송·제작 자료의 프로필 카드를 우선 확인하고 활용한다. 사용자가 제공한 카드가 있으면 새 이름표를 만들기 전에 그 자료를 기준으로 삼는다. 이름·직함뿐 아니라 주요 경력·저서가 포함된 프로필 형식을 고려한다.
- 이미지에서 관찰한 구성: 왼쪽 이름·직함·현직/전직 경력·저서, 오른쪽 인물 사진. 이 배치·색상·줄 수를 모든 출연자의 필수 템플릿으로 일반화하지 않는다.
- 편집적 의미에 대한 해석: 출연자가 어떤 경험을 토대로 말하는지 소개하는 역할이 단순 직함 풀이보다 중요하다. 이는 조수의 해석이며 사용자가 직접 설명한 이유로 인용하지 않는다.
- 미확정: 카드의 정확한 시작·종료 발화, 풀스크린 여부와 말자막 동시 노출 여부는 이 피드백만으로 확정하지 않는다. 오래된 카드의 현직 표기를 영구 최신 정보로 취급하지 않는다.

## 이후 피드백 기록 방식

발화 위치 → 조수 초안 → 사용자 선택 → 사용자가 밝힌 이유 → 다음 작업에 적용할 범위로 기록한다. 이유가 언급되지 않았다면 해석이라고 구분한다. 피드백을 받을 때마다 전체 Word를 재생성하지 말고 변경 내용을 누적해, 사용자가 반영을 요청하거나 검토가 끝나면 통합한다.
