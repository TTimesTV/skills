# 자막·자료 판단과 영상 아카이브 연결

사용자가 2026-09-07 승인한 실행 기준. 현재 명시 지시와 해당 시리즈 승인본이 우선한다. 이 문서 등록은 자동화 구현·업로드 완료를 의미하지 않는다.

## 자막의 선
- 말자막: 실제 발화 보존, 공백 포함 28자 상한·문법 결속 시 29자 허용. 음성·화면 교차검증, 임의 윤문 금지. 말자막 글자 제한을 강조·설명자막에 전용하지 않는다.
- 강조: 핵심 결론·반전·인과에만. 매 문장 재진술하지 않는다.
- 설명: 낯선 개념이 다음 말 이해를 막을 때, 대상이 무엇이며 무엇을 하는지 짧게 설명.
- 구조: 단계·항목을 기억해야 다음 설명이 이해될 때.
- 발화만으로 충분하거나 직전 화면이 이미 설명했다면 NONE. 초당/분당 개수 할당 금지.
- IN/변경/OUT은 실제 발화 앵커와 의미 완결 기준. 고정 초수나 임의 타임코드 금지.

## 자료 선택
검색 전에 역할을 정한다: 증명(원문·수치·실제 사건), 식별(제품·인물·시설), 작동 설명(움직임·구조). 역할 없는 분위기 자료 대신 출연자 화면 유지.
- 내부 레저: 사용 목적, 원출처, 원본 IN/OUT, 편집본 삽입 위치, 권리 상태.
- 원본 시각과 편집본 시각은 별도 필드. 추정 시각을 확정값으로 기록하지 않는다.
- Word 댓글 검토본은 `word-review-framing-20260917.md`가 우선한다. 원고에 제안 댓글, 해당 댓글에 선정 이유 답글을 달며 후보와 출처 링크를 허용한다. 다음 규칙은 명시적으로 요청된 인라인 실행본에 한한다.
- 인라인 실행 Word는 실행 지시만: 독립행 `//자막` 다음 확정 문구, 자료는 `//NN. (대상)_출처_(원본시각)_장면` 한 줄. 조사·검수 메모는 내부 레저.

## 팀 공통 자료 기록

- 현재 작업에서 팀원이 제공한 자료와 지정한 프로젝트 폴더를 사용한다.
- 후보/선택/실사용 상태, 출처 URL, 원본 IN/OUT, 편집본 위치, 선택 이유, 권리 상태와 검증 결과를 기록한다.
- 확보한 클립은 ffprobe와 실제 재생으로 확인하고 SHA-256을 기록한다. 링크만 기록한 항목과 실제 파일을 보관한 항목을 구분한다.
- 외부 계정 연결·자동 업로드·개인 보관함 동기화는 이 공유 스킬의 범위에 포함하지 않는다.
- 전체 원본 장기 보관, 편집 여유분 길이와 파일 정리는 현재 작업의 지시를 따른다.
- 세부 기록 항목은 `team-material-archive.md`를 참조한다.
