# 세 편의 초안과 사용자 최종 선택 비교

2026-09-30. 사용자 제공 박종천1편·2편·이제현 JSON을 기존 화면 구성 Word와 비교했다. 아래는 **해당 편의 승인 선택에서 얻은 적용 가능한 판단**이며 모든 주제의 고정 양식이 아니다. 상세 비교는 해당 작업의 `화면구성_초안과_승인본_비교.docx`와 `work/final_json/*_comparison.md`에 보존한다.

## 비교 집합의 한계

- 박종천1편: 보관된 자료설계420문단·댓글4개와 최종76배치. 보관본에 이미 사용자 피드백이 섞였으므로 모든 차이를 순수 AI 대 PD 저작 차이로 주장하지 않는다.
- 박종천2편: 제안67+답글67과 최종110배치. 이제현: 제안69+답글69와 최종121배치.
- 배치는 자막만이 아니라 자료·컷·교정·연결 표식을 포함한다. 단순 개수로 채택률·자막 밀도 비교 금지.
- CMS 자동 후보는 기존 Word 초안과 다른 집합이다. 사용하지 않은 후보를 곧바로 ‘내 제안이 거절됐다’고 계산하지 않는다.
- 최종 배치에 없는 문구는 ‘최종 목록에 없음’까지 확인된다. 삭제 이유를 사용자가 직접 말하지 않았다면 분석자의 해석이라고 밝힌다.

## 앞으로의 선택 판단

### 발화의 순간을 먼저 고른다

초안의 약점은 단순히 문장이 길다는 것보다 발화를 일반적인 개념으로 재정리하며 반전·인과·비유의 힘을 약하게 만드는 경우였다.

- 박종천2: ‘제한된 GPU 환경에서 / 작고 효율적인 모델 경쟁’ → ‘미국의 제재가 중국의 효율성을 키워버린...’.
- 박종천2: ‘큰 고객 중심에서 / 회사마다 한 대씩’ → ‘GPU 도매에서 소매까지 진출’.
- 이제현: ‘AI에게 일을 시키다 보니 / 이해되는 사장님 마음’ → ‘대표님, 이제야 깨달아요’.
- 박종천1: ‘다 만드는 능력보다 / 이해하고 연결하는 능력’ → ‘직접 만드는 것보단 잘 조립하는 게 훨씬 중요’.

후속 작업에서는 핵심 역설·비유·행동 동사가 빠지지 않았는지 확인한다. 이를 모든 자막을 자극적·확정적으로 강화하라는 규칙으로 읽지 않는다. 전망의 강도와 사실 범위는 계속 보존한다.

### JSON의 축약과 완성 화면의 생략을 구분한다

문서 비교 당시 박종천1의 인지 부채·소통 부채가 용어 이름만 남았다고 해석했으나, 2026-09-30 실제 공개 영상 확인으로 그 해석을 정정했다. [1편 03:26](https://www.youtube.com/watch?v=LLIxpEHR89M&t=206s)과 [03:29](https://www.youtube.com/watch?v=LLIxpEHR89M&t=209s)에 긴 정의 카드가 표시된다. JSON 항목의 문구는 자료 호출명이나 축약 지시일 수 있으므로 완성 화면의 전체 문구와 같다고 가정하지 않는다. 이 사례를 정의 카드를 줄이라는 선호의 근거로 사용하지 않는다.

공개 영상이 있을 때는 기존 제안 → 승인 지시 → 실제 구현을 구분한다. 영상의 시각과 원고 블록 시각도 구분하며, 탐색 직후에는 실제 프레임과 플레이어 시각이 안정됐는지 확인한다. 대표 장면만 확인했으면 전편 시청으로 보고하지 않는다.

같은 날 확인한 실제 구현: 1편 15:24·16:04는 0~2단계에서 0~4단계로 그래픽을 누적하며 작은 인물을 유지한다. 20:54·21:04는 지능·지식·지시의 X/O를 바꾼다. 2편 [15:17](https://www.youtube.com/watch?v=T6xvPdwM1Js&t=917s)은 AAI 표 주변을 어둡게 하고 해당 막대만 강조한다. 23:55는 회사 로고만 말자막 위에 작게 표시한다. 26:40·26:55의 지출 자료는 원표 그대로가 아니라 항목별 카드와 전체 구도로 재구성된다. 이 관찰은 자료 선택과 구현의 차이를 이해하는 근거이며 제작자의 개별 기여를 단정하는 근거가 아니다. 이제현은 미공개로 영상 대조하지 않았다.

### 노출 구간은 선정 이유의 범위보다 짧을 수 있다

이제현 ‘부서 전체의 병목을 알고 / 바꿀 권한도 있는 사람’은 ‘부서장’으로 구체화되며 B20 [107:159] 결론 절에 연결됐다. 이전의 병목·용역비 사례 전체는 선정 근거이지 화면에 계속 띄울 범위가 아니다. 문구가 맞는지와 어느 절에 걸리는지를 별도로 검토한다.

### 자료는 실제로 볼 대상을 지정한다

- 박종천1: ‘자는 동안 큰 거 하나…’ → 실제 캡처의 ‘5시간 리밋(92%) 부근’에 코멘트.
- 박종천2: 새 모델 분류판보다 AAI 인덱스의 해당 점·모델을 강조.
- 이제현: 역사 교재의 구석기·왕자의 난·만세·퀴즈·부모용 답안·거북선을 별도 사진으로 각 발화에 대응.

일반적인 ‘AI 자료’나 회사 공식 페이지를 가져오는 것보다 눈이 가야 할 부분과 그것이 발화에 대응하는 이유가 중요하다. 실제 화면이 확보되어 제작 단계가 진행된 변화는 문체·취향 변화와 구분한다.

### 식별과 입증과 관계 설명을 나눈다

박종천2의 두 국내 회사는 공식 서비스 페이지 설명 대신 ‘로고 말자막 위에 작게’로 식별하고, 용어·주장 구간에서는 LLMOps·기사로 바꿨다. 로고로 충분한 순간에 과한 설명 화면을 만들지 않는다. 기사 사용은 그 제목·본문이 해당 주장과 맞는지 확인하는 별도 판단이다. 매체명만 있다고 검증 완료가 되지 않는다.

### 기준 그래픽을 재사용하고 변화만 짧게 지시한다

박종천1의 07번 독스 자료를 인물과 병치해 재사용, 박종천2의 1편 풀스택 그래픽 재사용, 이제현의33번 in/on/out 그래픽 재사용이 있다. 관계·순서가 중요하면 한 기준 화면으로 이해를 이어가게 한다. X 표시와 취소, 항목별 강조처럼 명시된 동작은 별도로 보존하고, 단지 줄이 여러 개라는 이유로 애니메이션을 만들지 않는다. ‘로고 암데나’ 같은 편집자 재량도 임의 좌표로 닫지 않는다.

### 팩트 확인을 짧고 구체적인 교정으로 연결한다

이제현 논문 피드백 비율의 80% 문제는 최종에 ‘80% 아니고57%’와 ‘57.4%는 도움 된다고 응답’으로 반영됐다. 확인 문제를 길게 반복하는 대신 검증된 분모·지표와 실제 수정 행동을 연결한다. 원고 발화와 교정 지시는 다른 층이므로 복원 과정에서 원고를 몰래 고치지 않는다.

## 그대로 학습하면 안 되는 것

- 파이널의 오타(예: ‘있있다’), 제품 버전·지표·기간 없는 수치, B2C/B2B 의심 표기는 선호나 사실 규칙이 아니다.
- 기사·그래픽·매출표의 승인 선택은 해당 외부 사실·권리를 검증했다는 뜻이 아니다.
- 전망을 강하게 쓴 한 사례가 모든 조심스러운 발화를 단정형으로 바꿀 권한은 아니다.
- 특정 프로그램·출연자의 농담, 강수진 시연을 본뜬 반쪽 화면, 특정 회사 장면은 주제·자료 조건이 같을 때만 참고한다.
- 실제 미디어가 없는 JSON 복원은 문구·앵커의 복원이지 완성 영상·프레임 검증이 아니다.
