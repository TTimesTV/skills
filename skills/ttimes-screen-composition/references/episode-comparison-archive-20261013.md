# 회차별 초안과 최종 선택 비교 기록

사용자 요청: 각 편의 차이 보고서를 작성하고 축적한다. 이 문서는 보고서 저장 규칙이며 외부 게시나 영상 변경 권한을 추가하지 않는다.

## 보관 위치

- 루트: `LOCAL_REFERENCE_NOT_DISTRIBUTED`
- 목록: `보고서목록_20261013.json`, `화면구성 비교보고서 통합목록_20261013.docx`
- 회차 폴더에 날짜가 붙은 Word 보고서, `비교근거_날짜.json`, `근거`의 입력 스냅샷·SHA-256을 남긴다.
- 완료 회차: 이제현, 박종천 1·2편, 강정수 1·2편, 김지현 정도희 1편, 박영선 유호현, 이중학 송지훈.
- JSON 대기: 김지현 정도희 2편, 음재훈 1·2편, 이건복 1·2편. 대기 상태는 새 입력을 받으면 재확인한다.

## 비교 단위와 버전

초안과 사용자 최종 선택의 정확 문구·발화 앵커·자료 지시를 함께 남긴다. 문구, 질문의 초점, 자료 기능, 구도, 등장·변경·유지·종료, 원문 컷, 교정, 제작 진전을 구분한다. 유지와 대응 미확정도 기록한다. 대표 사례 외 전체 초안/최종 기록을 근거에 보존한다.

강정수 1편의 1-1·1-2는 한 회차다. 강정수 2편의 10월 8일 교정 36개를 화면구성 변경 36개로 부르지 않는다. 박영선 유호현 10월 13일 JSON은 약 39분 원고이며 약 33분 유튜브본과 시각이 다르다. 같은 원고의 v3 초안을 주 비교본으로 삼고 최근본은 별도 이력으로 본다. 김지현 정도희 1편은 최초 문구와 최근 하이라이트 범위 수정을 구분한다.

9월 30일 세 회차는 보존 추출본이 근거이며 원본 JSON 재확보와 구분한다. 박종천 1편 보관 기존안은 이미 사용자 편집이 섞인 혼합본이다. 파일 경로가 옮겨지거나 원본을 못 찾으면 실제 확보 상태를 적고 순수 AI 최초안으로 귀속하지 않는다.

사용자 지정 파이널이라도 used, 직접 입력한 manual pending, 자동 pending, discarded를 구별한다. 자동 pending은 최종 선택에 섞지 않는다. 직접 입력한 pending도 실제 방송 구현 완료로 인증하지 않는다. 문자 앵커 없는 그래픽이나 점·쉼표 표식을 임의 종료 지시로 만들지 않는다.

## 새 사례가 바꾸는 판단

- 박영선 유호현 S11과 F12–18: 전화→앱→에이전트를 한 줄로 끝내지 않고 전화·앱 사진의 재사용, 말풍선 영상, 가게 에이전트 관계도로 순서를 보여준다. 단계마다 새 자료를 무조건 만들라는 뜻은 아니다.
- 박영선 유호현 S13과 F9–11: 진행자의 재진술도 실제 제품 시연을 배치할 구간이다. 얼굴과 시연의 병치, 종료 문장이 선택된 경우 이를 함께 보존한다.
- 박영선 유호현 S52와 F90–95: 반전을 앞에서 요약하면 반응이 사라진다. 긍정 문구의 유지와 뒤집는 발언을 분리해 검토한다.
- 이중학 송지훈 S36과 F39–45: 기사 확보에서 멈추지 않고 차트의 어느 부분을 번역·강조해 무슨 결과를 읽게 할지 지정한다. 차트 수치와 연구 모집단의 사실 검증은 별도다.
- 이중학 송지훈 F5·22와 F50–51·62: 같은 회차에도 용어만 기록된 항목과 긴 정의가 공존한다. 기술 주제라는 이유만으로 설명량을 고정하지 않는다. JSON의 짧은 표기만으로 영상에서 정의를 뺐다고 추정하지 않는다. 박종천 1편 인지·소통 부채 정의 카드 정정 사례가 반례다.
- 이중학 송지훈 S49와 F59–61: 질문→짧은 반응→결론을 발화 앵커 순서로 읽는다. JSON 배열 순서를 영상 등장 순서로 대체하지 않는다.

이 관찰들은 기존 회차에서도 반복된 발화 전개·구체적 시각 대상 선택의 사례다. 특정 인물은 항상 그래픽, HR은 항상 자막 같은 인물·주제 결정 규칙으로 확대하지 않는다. 초안의 유효한 문구·구조가 유지된 사례를 함께 본다.

## 미해결 사항을 학습하지 않기

이중학 송지훈의 행사 날짜는 원문/최종 앵커가 다르고 F49는 미연결 pending이다. 박영선 유호현의 카카오톡·멀티프러너 메모는 사실 또는 용어 문제의 기록이다. 이 내부 메모를 검증을 생략하라는 지시나 승인된 사실로 사용하지 않는다. 비례 기호·경제 수식도 출연자 설명과 검증된 법칙을 구분한다.

이번 JEV 2회는 입력 17,876, 출력 1,256토큰이었다. 회차별 동일 라벨 반복이 관찰되어 전체 대표 사례를 수동 재판정했다. 다음 비교도 JEV의 분류를 바로 집계하지 말고 문구·자료·전개를 독립 검토한다. 승인된 과거 분석을 보고서로 옮기는 데에는 재호출하지 않는다.
