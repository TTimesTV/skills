## 최종 Word의 실제 문법

### 색과 인접성

- 검정/기본색: 원고 본문
- 노랑 하이라이트 + 청록 굵게: 생산객체
- 노랑 객체 바로 뒤 청록 무하이라이트 run: 그 객체의 정확한 적용 발화
- 청록에서 검정으로 복귀: OUT
- 빨강: 국소 교정·주의·비정형 메모
- 문단 내부에서 청록→검정 전환이 가능하므로 run 단위로 처리한다.

전체 원고를 청록으로 바꾸지 않는다. 명시적 `IN/OUT` 문장을 반복하지 않는다.

### 자막

```text
//자막
반도체 피크아웃 vs 반도체 슈퍼사이클
```

- `//자막`은 독립 문단이다.
- 확정 화면 문구는 다음 노란 문단에 둔다.
- 자료 ID·기능 코드·렌더 코드·`YES_EXACT`·기본 말자막 상태를 노출하지 않는다.
- 자막은 자료의 제목이 아니라 발화의 강한 판단, 반전, 비유, 공식, 정의, 관계, 근거, 결론에서 독립적으로 고른다.
- 질문자막은 선택적이다.
- 짧은 펀치와 긴 개념 설명을 모두 허용하며 모든 자막을 균일한 2행 헤드라인으로 만들지 않는다.

관측 예:

```text
말도 안 되는 소리
AI 매출 = 토큰 소비량 x 토큰 가격
대다수는 체감하지 못하는 AI 호황
```

### 자료 호출

```text
//NN. (대상·자료명)_출처_(원본 시각)_쓸 장면·재량
```

예:

```text
//01. (Google I/O)_Google_(~38초~)_그냥 차트 올라가는 영상
//03. (AMD 칩)_AMD_(4초~ 등)_(칩 쌓이는 장면...)
//04. (관련 기사 캡쳐)_머니투데이
```

- 보통 한 줄이다.
- 해당 발화 바로 앞 배치와 뒤 청록 run이 타임라인을 전달한다.
- `아무 장면`, `그냥 말하는 장면`, `재탕`, `영상 끝?`은 편집자 재량을 허용하는 완료된 지시다.
- 같은 파일의 재사용은 같은 `//NN`을 다시 부른다.
- 복잡한 배치는 장문 대신 화면 참고 이미지를 삽입할 수 있다.

## 산출물 상태 구분

### 자료설계·자료요청

아직 실제 자산이 선택되지 않은 상태다. 내부 또는 별도 문서에 다음을 둘 수 있다.

- 후보 출처
- 검색어
- 포함/제외 기준
- 팩트·권리 상태
- 영상 브리프
- 미확인 수치

이 상태를 `자료-완료`라고 부르지 않는다.

### 자료-완료

- 실제 선택·전달된 자산에 번호가 있다.
- 영상이면 필요한 경우 원본 시각 또는 식별 가능한 장면이 있다.
- Word 본문에는 한 줄 자료 호출과 정확한 청록 싱크만 둔다.
- 팩트·권리·검색·기능·상태 메타데이터는 내부 레저에 남긴다.
- 편집 결과를 바꾸는 경고만 해당 위치에 빨간 한 줄로 둔다.

## 안티패턴

- 모든 원고를 청록으로 칠하기
- `ID`, 기능, 등장, 렌더, 문구고정, 자료필요도, 구현 상태를 Word에 출력하기
- 모든 자료마다 `IN/OUT`, 출처, 검색어, 말자막 상태를 반복하기
- 여러 줄을 한 문단의 `<w:br/>` 블록으로 뭉치기
- 자료 미선정 상태에서 파일명을 `자료-완료`로 정하기
- 자막을 자료 그래픽의 제목으로만 만들기
- 모든 자막을 2행형으로 균질화하기
- 모든 질문을 `Q.` 카드로 만들기

## 최종 QA

- [ ] 검정 본문이 기본이며 청록은 실제 싱크 run에만 적용됐는가
- [ ] 검정 복귀가 각 객체의 OUT을 복원하는가
- [ ] `//자막`과 확정 문구가 별도 노란 문단인가
- [ ] 번호 자료 호출이 실제 선택 자산을 가리키는가
- [ ] 자료 호출은 특별한 이유가 없으면 한 줄인가
- [ ] `ID/기능/상태/검색/권리/기본 말자막/명시적 IN·OUT`이 본문에서 제거됐는가
- [ ] 재사용 자산은 동일 번호인가
- [ ] 자막이 자료와 독립적으로 발화의 말맛·정의·반전·결론을 잡았는가
- [ ] 상세 팩트와 검색 이력은 내부 레저에 남아 있는가
- [ ] 선택되지 않은 자산이 있다면 문서명이 `자료설계` 또는 `자료요청`인가
