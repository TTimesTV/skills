# 팀 공통 자료 목록

현재 프로젝트에서 사용한 자료의 출처와 검증 상태를 팀원이 재확인할 수 있도록 기록한다. 특정 개인 계정, 노트 앱, 클라우드 연결을 전제하지 않는다.

## 항목

- material_id 또는 clip_id
- 원본 URL·제목·채널·게시일
- 원본 IN/OUT과 실제 추출 IN/OUT
- 편집본 사용 위치와 선택 이유
- 후보/선택/실사용 상태
- 현재 프로젝트 기준 상대 파일 경로
- 권리·출처 표기 조건
- 파일 크기, SHA-256, ffprobe 및 재생 검증 결과
- 사용 이력과 검증 담당자

## 검증과 전달

실제 파일은 미디어 디코딩·재생을 확인한다. URL만 있는 항목은 출처 기록으로 표시한다. 최종 편집 지시와 자료 목록은 같은 자료 ID를 사용한다. 다른 팀원에게 전달할 때 파일 목록과 해시로 누락을 확인한다.

외부 저장소 연결이나 자동 업로드는 포함하지 않는다. 필요한 공유 위치는 해당 작업에서 팀원이 제공해야 한다. 기존 파일 삭제·덮어쓰기는 현재 작업의 지시를 따른다.
