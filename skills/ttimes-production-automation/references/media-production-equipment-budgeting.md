# 미디어 제작 장비 예산 산정

미디어 매체의 장비 질문은 카메라 모델 나열이 아니라 **운영 단위별 완성 세트 비용**으로 답한다.

## 먼저 구분할 제작 등급

1. 소형 디지털 매체·사내 유튜브
2. 취재팀 + 고정형 2~3캠 인터뷰 스튜디오
3. 방송국·중계·영화급 시설

같은 `카메라`라도 등급별 요구사항이 다르다. 미러리스 화질만 비교하지 말고 장시간 녹화, XLR, SDI, 타임코드, 전자식 ND, 상시전원, 원격제어, 멀티캠 색 일치가 필요한지 확인한다.

## 반드시 분리해서 견적낼 항목

- 편집석: 본체, GUI 모니터, 색 확인 모니터, 캘리브레이터
- 야외 카메라 세트: 바디, 렌즈, 미디어, 배터리, 케이지, 외장 모니터, ND, 가방
- 스튜디오 카메라 세트: 바디, 렌즈, 비디오 삼각대, 상시전원, SDI/HDMI, 프롬프터
- 음향: 무선 핀마이크, 샷건/붐, 레코더·믹서, 헤드폰, 케이블
- 조명: 키·필·백라이트, 스탠드, 소프트박스, 그립
- 인프라: NAS, 3-2-1 백업, 스위처, 인터컴, 방음·흡음, 전기·배선
- 반복비용: Adobe/NLE, 음원·스톡, 클라우드, 보험, 수리·소모품

카메라 바디 가격을 전체 촬영비로 제시하지 않는다. 실제 출동 가능한 카메라 세트는 렌즈와 액세서리 때문에 바디 가격보다 크게 높아진다.

## 답변 형식

1. 사용 등급별 결론과 총예산
2. 모니터·본체·야외 카메라·스튜디오 카메라·마이크를 각각 `실무형 / 전문형`으로 구분
3. 각 항목에 대표 사양 또는 제품군, 단품 가격대, 완성 세트 가격대
4. 빠지기 쉬운 조명·삼각대·스토리지·세트 공사 비용
5. 장비 구매와 대여의 경계

## 산정 원칙

- 가격은 답변 시점의 제조사 공식 판매가와 현재 국내 실판매가를 다시 확인한다.
- 단종·병행수입·일시 할인가는 표준 예산의 근거로 삼지 않는다.
- 동일 모델의 `바디`, `렌즈 키트`, `액세서리 패키지` 가격을 혼동하지 않는다.
- 편집 PC는 CPU/GPU 이름만 쓰지 말고 RAM, 작업 SSD, 캐시/스크래치, 코덱·멀티캠·AI 사용 조건을 함께 적는다.
- 모니터는 GUI 편집용과 색보정·방송 레퍼런스용을 구분한다. 4K라는 이유만으로 색보정용이라고 부르지 않는다.
- 무선 오디오는 편한 2.4GHz 크리에이터 제품과 혼잡 환경에 강한 방송용 UHF 계열을 구분한다.
- 총액은 반드시 항목별 범위를 기계적으로 합산해 검산한다.

## 구매보다 대여가 나은 경우

- 월 촬영 횟수가 적은 FX6·C400 이상 고가 카메라
- 고급 방송 렌즈, 장망원, 대형 조명, 짐벌·크레인
- 행사 중계용 스위처·인터컴·다채널 무선 시스템

반대로 편집석, 기본 음향, 기본 조명, 저장·백업은 반복 사용되므로 보유 가치가 높다.

## 주의

특정 매체가 실제로 무엇을 쓰는지 묻는 경우에는 추정하지 말고, 현장 사진·장비 크레딧·채용 공고·납품 규격·공식 BTS 등 직접 근거를 찾는다. 일반 업계 예산과 특정 회사 보유 장비를 혼동하지 않는다.
