# 2026-07-08 TTimes 말자막: /plan + 서술어 부착 워크플로우

## 왜 저장했나

사용자가 여러 차례 품질을 지적한 뒤, `/plan`으로 업무 순서와 우선순위를 먼저 고정하고 재작업했을 때 품질이 크게 올라갔다. 앞으로 TTimes/말자막/SRT 작업은 이 흐름을 기본값으로 삼는다.

## 핵심 교훈

좋은 품질은 `27자 이하 packing`이 아니라 **작은 말문장**에서 나온다.

최종 우선순위:

1. 문장/생각 종결: 문장이 끝나면 웬만하면 다음 cue로 넘긴다.
2. 서술어 부착: 목적어/부사어/시간어를 서술어 없이 고립시키지 않는다.
3. 작은문장성: cue 하나가 가능하면 `대상/목적어 + 동사/판단/서술어`로 읽힌다.
4. 접착어 보호: 접속어, 정도부사, 지시어, 의존명사, 보조용언을 고립시키지 않는다.
5. 말 리듬.
6. 25자 목표 / 27자 max.

## 반드시 /plan으로 먼저 고정할 것

실행 전에 다음을 짧게 고정한다.

```text
1. 재사용할 것: MP3/ASR/확정 용어/고신뢰 ASR 수정
2. 폐기할 것: 잘못된 분절/최종 후보본
3. 최상위 룰: 문장종결 + 서술어 부착
4. subagent 검수 기준: 목적어·부사어·시간어 고립 cue 찾기
5. 최종 검증: body exact match, 27자 초과 0, 마침표 0, overlap 0
```

## 실패 사례

```text
지난주 금요일에 집을 다
그렇게 꾸며놨어요 일하기 적합하게
```

문제:
- `집을 다`가 목적어/부사 덩어리만 남고 서술어가 없다.
- `그렇게 꾸며놨어요 일하기 적합하게`도 어순이 불편하다.
- 27자 이하라도 말자막으로는 0점.

## 좋은 방향

```text
아니 뭐 사무실까지 저 집을 이사 갔거든요
지난주 금요일에
집을 다 일하기 적합하게 꾸며놨어요
```

또는 문맥에 따라:

```text
지난주 금요일에 이사 갔거든요
```

## subagent 브리프 필수 문구

```text
각 cue를 단독으로 읽어라.
목적어/부사어/시간어만 있고 서술어가 다음 cue에 있으면 오류다.
짧은 cue라도 인사/응답/화제제시가 아니면 의심하라.
문장 끝+다음 문장 억지 병합도 찾아라.
고유명사/숫자/단위 오류도 같이 찾되, 과한 윤문은 하지 말라.
```

## 검증 체크리스트

기계 검증:

```text
script lines == srt cues
SRT body exact match
27자 초과 0
마침표 0
overlap 0
nonpositive 0
```

텍스트/분절 검증:

```text
목적어 고립 cue 없음
부사어 고립 cue 없음
시간어+목적어만 있는 cue 없음
정도부사 고립 없음
보조용언 split 없음
접속어 단독 없음
문장 끝+다음 문장 억지 병합 없음
```

## 최종 원칙

```text
문장 끝에서 끊되,
목적어/부사어/시간어를 서술어 없이 고립시키지 않는다.
```
