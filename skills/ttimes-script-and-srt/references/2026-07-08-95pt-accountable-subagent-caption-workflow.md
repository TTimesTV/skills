# 2026-07-08 — 95점 책임제 + subagent 회의형 TTimes 자막 워크플로

## 배경
사용자가 TTimes 말자막 품질에 강하게 피드백했다. 핵심은 “토큰/도구를 많이 쓰는 것”이 아니라, 편집자가 철학과 책임감을 가지고 최종본을 만들어야 한다는 것.

실패 사례:
- 25자 제한을 기계적으로 맞추며 `어떤 / 전쟁`, `설명해주셨던 / 게`, `하나하나 좀 / 각개격파해서`, `AWS, / GCP`처럼 결합구·리스트를 깨뜨림.
- subagent cue 후보를 최종본처럼 사용하거나 자동 병합/분절 결과를 spot-check 없이 납품.
- `max chars`, `body exact match`, `overlap 0` 같은 기계 검증만으로 품질을 과신.
- 원문교정이 과한 윤문/요약/생략으로 변질.

## 사용자 기준
- 사용자는 30만 원을 내고 Hermes를 고용하고 있다는 관점. “95점”이라 말하고 실제 80점 이하 품질이면 시간/돈 낭비로 본다.
- 95점이라고 납품했는데 사용자가 오류 5개 이상 찾으면 OUT. 변명하지 말고 실패 인정 후 재작업.
- 80점 이하 사고 시 다음 작업은 패널티 모드: 최종 납품 권한 제한, 샘플 승인제, 98점 게이트, subagent 2차 검수, 실패 원인 보고서.

## 필수 작업 철학
- 자막은 글자 수 맞추기 게임이 아니다.
- 원문을 새로 쓰지 말고, 원문을 망치지 않는 선에서 방송 자막으로 정리한다.
- 25자 제한은 안전장치일 뿐, 분절 기준은 의미 완결·한국어 문장 성분·시청 리듬이다.
- subagent는 참고 리뷰어이고, 최종 책임은 Main Hermes가 진다.
- “검증 수치 좋음”은 납품 근거가 아니다. 실제 눈으로 읽어야 한다.

## Subagent 회의 운영
작업 시작 시 `/goal` 형태로 목표를 고정하고, 중간 회의록을 사용자에게 보고한다.

회의록 포맷:
```text
[회의록 N]
참여 에이전트:
A. 원문보존/ASR 오류 담당
B. 가독성/분절 담당
C. 누락·윤문·왜곡 검수 담당
D. 반박검수/95점 게이트 담당

각 에이전트 보고:
- A: 발견 사항
- B: 분절 원칙/위험 구간
- C: 생략·윤문·왜곡 위험
- D: 납품 가능/불가능 판단

Main Hermes 판정:
- 채택 / 보류 / 반려
- 이유

다음 액션:
- 반영할 수정
- 추가 확인할 구간
```

운영 원칙:
- subagent에게 “최종 자막 전체 작성”을 맡기지 말고 line/time 기준의 문제·제안만 받는다.
- Main Hermes는 각 제안을 채택/보류/반려하고 이유를 기록한다.
- 회의 결과를 기계적으로 반영하지 말고, 한국어 결합구와 실제 읽힘을 기준으로 재판단한다.

## 95점 게이트
시작 100점. 최종 review에서 눈에 보이는 오류 1개당 -1점. 95점 미만이면 보내지 않는다.

감점 대상:
- 결합구/문장성분 깨짐: `어떤 / 전쟁`, `설명해주셨던 / 게`, `하나하나 좀 / 각개격파해서`, `할 수 / 있다`.
- 리스트 분리: `애저, AWS, / GCP, 콜로서스`.
- ASR/고유명사/표기: `ai` 미통일, `지신`, `지피우`, `계획이 세우는`.
- 25자/예외 기준 위반.
- 윤문·요약·생략·의미 drift.
- low-match cue 미확인, SRT body/timing 오류.

최종 전 필수:
1. 기계 검증: body exact, overlaps, nonpositive, max chars, low-match.
2. lint hits 전수 확인.
3. 첫 3분, 중간 3분, 후반 3분 직접 읽기.
4. 용어 밀집/인용문/리스트 구간 직접 읽기.
5. 감점표와 자체 점수 기록.

## 80점 이하 사고 패널티
사용자가 실제 품질을 80점 이하로 판정하면:
1. 납품 무효.
2. 같은 영상 처음부터 재작업.
3. 다음 1회는 98점 게이트.
4. 사용자 승인 전 “완료/최종/95점” 표현 금지.
5. 샘플 승인제: 00:00~03:00, 용어 밀집, 인용문, 후반 샘플을 먼저 제시.
6. subagent 2차 검수 의무화.
7. 실패 원인 보고서 작성: 오류 / 원인 / 단계 책임 / 방지 규칙 / 재검수 방법.

## 적용 메모
새 MP3/YouTube 작업에서는 최종 납품 전 회의록 요약을 사용자에게 중간 보고하고, “Main Hermes가 무엇을 받아들이고 무엇을 반려했는지”를 투명하게 남긴다.
